## 使用须知

### 系统要求

| 项目 | 要求 |
|---|---|
| **操作系统** | Windows 7 / 8 / 8.1 / 10 / 11（仅 64 位） |
| **依赖组件** | Microsoft .NET Framework 4.8、Microsoft Edge WebView2 |
| **网络** | 正常网络连接，可访问下载服务 |
| **权限** | 建议具备管理员权限，以便安装依赖组件 |

<Info>
**提示**：安装程序会自动检测依赖组件是否已安装。如果未安装，会自动下载安装。如自动安装失败，请参考下方[常见问题](#安装常见问题)手动处理。
</Info>

## 下载安装 RPA 客户端

<Steps>
  <Step title="下载安装包">
    访问 [八爪鱼 RPA 下载中心](https://rpa.bazhuayu.com/download)，下载八爪鱼 RPA 安装文件（`.exe`），获取最新版本程序。

    <Info>安装前建议先**关闭所有杀毒软件**，避免安装过程被安全软件拦截。</Info>
  </Step>
  <Step title="运行安装程序">
    双击 `.exe` 文件开始安装。安装程序会自动检测并安装缺失的依赖组件（.NET Framework 4.8、Edge WebView2）。
  </Step>
  <Step title="完成安装">
    安装完成后，在开始菜单或桌面上找到 **八爪鱼 RPA** 快捷方式。
  </Step>
  <Step title="登录启动">
    启动八爪鱼 RPA，使用您的账号登录。首次启动后即可进入主界面，开始搭建您的第一个自动化流程。
  </Step>
</Steps>

## 安装常见问题

<AccordionGroup>
  <Accordion title="安装向导执行失败：0x80070490 - 找不到元素">

**原因**：.NET Framework 4.8 未安装或安装不完整。

**解决办法**：手动下载 .NET Framework 4.8 离线安装包。

- [Microsoft .NET Framework 4.8 安装包](https://update.bazhuayu.com/rpa_client/ndp48-x86-x64-allos-enu.exe)

**Win7 系统额外步骤**：

1. 确保系统是 Win7 SP1。如果不是，请先安装 [Win7 SP1（x64）](https://catalog.s.download.windowsupdate.com/msdownload/update/software/svpk/2011/02/windows6.1-kb976932-x64_74865ef2562006e51d7f9333b4a8d45b7a749dab.exe)
2. 双击安装 [Microsoft 根证书](https://resource-wangsu.helplook.net/docker_production/ja1cid/article/nzlIEF/attachments/MicrosoftRootCertificateAuthority2011.cer)
3. 安装 [KB2813430 补丁](https://resource-wangsu.helplook.net/docker_production/ja1cid/article/nzlIEF/attachments/Windows6.1-KB2813430-x64.msu)（解决"时间戳签名和或证书无法验证或已损坏"问题）
4. 重启电脑后安装 .NET Framework 4.8

  </Accordion>
  <Accordion title="安装向导执行失败：0x80070643 - 安装时发生严重错误">

**可能原因**：

- **杀毒软件阻止安装**：检查后台运行的杀毒软件，关闭后重试。
- **Edge WebView2 组件在线安装失败**：手动下载离线安装包。

   → [Microsoft Edge WebView2 安装包](https://update.bazhuayu.com/rpa_client/MicrosoftEdgeWebView2RuntimeInstallerX64.exe)

  </Accordion>
  <Accordion title='提示"您已安装更新版本的客户端"'>

打开 **控制面板 → 程序和功能**，检查当前已安装的八爪鱼 RPA 版本：

- 如果想安装更低版本 → 先卸载当前版本，再重新安装
- 如果想安装当前版本 → 忽略错误即可

  </Accordion>
</AccordionGroup>

## 可选：安装 RPA 机器人

> 八爪鱼 RPA 客户端集成了设计器、执行器和控制器。RPA 机器人是独立的纯执行器，用于在**不同设备上并行运行多个流程应用**。

<Info>
**前期不需要安装机器人**。个人用户使用 RPA 客户端即可满足日常开发与执行需求。仅在以下场景考虑安装机器人：

- 需要在多台设备上同时运行多个自动化流程
- 企业版用户需要扩展运行器数量、实现分布式执行

机器人属于付费功能，详情请参见 [八爪鱼 RPA 定价](https://rpa.bazhuayu.com/plan)。
</Info>

如需安装机器人，访问 [八爪鱼 RPA 下载中心](https://rpa.bazhuayu.com/download)，选择 **"机器人"** 下载对应安装包。安装后登录有机器人使用权限的账号，即可在客户端的"机器人"模块中管理和调度运行。
