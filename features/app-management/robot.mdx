## 功能概述

机器人是八爪鱼RPA 中负责实际执行自动化任务的运行实例。一个账号可拥有多个机器人，通过机器人可以实现同时运行多个应用、智能排队与任务调度，从而提升自动化任务的吞吐效率。

## 入口

在八爪鱼RPA 客户端左侧导航栏点击 **机器人** 即可查看当前账号下的所有机器人。

## 页面结构

| 区域 | 说明 |
| --- | --- |
| 机器人列表 | 展示账号下所有机器人的名称、状态与归属 |
| 机器人数量 | 列表后方数字表示当前拥有的机器人数量，0 表示未购买机器人 |
| 详情入口 | 点击机器人可查看详情，复制机器人 ID 等 |

## 主要功能

### 查看机器人状态

在机器人列表中可以查看每个机器人的在线状态、当前任务、版本信息等，便于管理员掌握整体运行资源。

### 获取机器人 ID

部分功能（如 Webhook 触发器）需要指定机器人在哪个机器人上运行。点击机器人「详情」即可复制机器人 ID。

### 多任务并发

拥有多个机器人时，系统可对应用运行进行智能排队与并发调度，机器人越多，可同时执行的任务越多。

## 使用流程

1. 进入「机器人」模块，确认当前账号拥有的机器人数量与状态。
2. 在设置触发器或 Webhook 时，选择指定机器人运行应用。
3. 通过「运行日志」查看各机器人上的任务执行情况。
