## 功能概述

应用管理界面是查看与管理所有已开发应用的入口。在这里可以新建应用、编辑已有流程、运行应用、分享给他人，以及查看应用的基本信息与版本状态。

## 入口

在八爪鱼RPA 客户端左侧导航栏点击 **应用** → **我的应用** 即可进入应用管理界面。

## 页面结构

| 区域 | 说明 |
| --- | --- |
| 应用列表 | 以卡片或列表形式展示当前账号/企业空间下的所有应用 |
| 新建应用 | 创建空白应用并进入流程编辑界面 |
| 搜索/筛选 | 按名称、标签或分类快速定位应用 |
| 操作入口 | 每个应用卡片提供编辑、运行、分享、删除等快捷操作 |

## 主要功能

### 新建或编辑应用

- **新建应用**：点击「新建应用」按钮，选择空白应用或基于模板创建，进入流程编辑界面。
- **编辑应用**：在应用列表中选择目标应用，点击「编辑应用」，或双击应用卡片，即可进入流程编辑页面修改流程。

### 运行应用

点击应用卡片上的「运行」按钮，即可启动当前应用。系统会按照流程编排自动执行，运行状态可在「运行日志」中查看。

### 分享应用

点击「分享」可将应用以链接或账号方式分享给他人：

- **普通用户**：可链接分享或账号分享给个人用户，无法分享给企业账号。
- **开发者**：应用发版后可分享给个人或企业用户，支持设置「可使用」「可编辑」「分享副本」等权限，并可限制可用时长。

## 使用流程

1. 进入「我的应用」查看已有应用列表。
2. 点击「新建应用」或选择已有应用进行编辑。
3. 在流程编辑器中搭建、调试并保存流程。
4. 返回应用管理界面，点击「运行」验证效果。
5. 按需点击「分享」，将应用分发给团队成员或社区用户。
