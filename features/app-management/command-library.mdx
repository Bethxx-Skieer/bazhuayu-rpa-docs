## 功能概述

指令库是八爪鱼RPA 中所有可用指令的集中入口。无论是网页自动化、桌面自动化、Excel 操作、数据处理还是 AI 能力，都可以通过指令库快速查找并拖入流程中使用。同时支持收藏常用指令，提升开发效率。

## 入口

在八爪鱼RPA 客户端左侧导航栏点击 **指令库** 即可进入。

## 页面结构

| 区域 | 说明 |
| --- | --- |
| 指令分类 | 按功能维度划分，如条件判断、循环、网页自动化、Excel、AI 等 |
| 搜索框 | 输入指令名称或关键词，快速定位所需指令 |
| 指令列表 | 展示指令名称与简要说明 |
| 我的收藏 | 高频指令可收藏至此，相当于常用指令置顶 |

## 主要功能

### 浏览指令

指令按功能模块组织，常见分类包括：

| 分类 | 说明 |
| --- | --- |
| 条件判断 | if、else、if 元素可见等分支控制指令 |
| 循环 | while、for each、按次数循环等 |
| 网页自动化 | 打开网页、点击元素、填写输入框、数据提取等 |
| 桌面自动化 | 操作 Windows 窗口与桌面元素 |
| Excel | 读写单元格、操作 Sheet、筛选数据等 |
| 数据处理 | 文本处理、日期转换、JSON 解析、列表/字典操作 |
| AI | 交互式对话、文本生成、摘要、翻译、OCR 等 |
| 群通知 | 飞书、钉钉、企业微信群机器人通知 |

### 搜索指令

在指令库顶部的搜索框中输入关键词（如「点击」「Excel」「截图」），系统会模糊匹配指令名称与说明，快速定位目标指令。

### 收藏指令

对于高频使用的指令，可右键或点击收藏按钮加入「我的收藏」，在流程编辑时无需反复翻找分类。

### 使用指令

在流程编辑界面中，从指令库按住目标指令并拖拽至中间流程栏，或在流程栏当前行点击「添加指令」后选择，即可完成指令添加。

## 使用流程

1. 打开指令库，按分类浏览或通过搜索框定位指令。
2. 将目标指令拖入流程编辑区。
3. 在右侧参数栏填写指令所需的参数。
4. 保存并运行应用，验证指令执行效果。
