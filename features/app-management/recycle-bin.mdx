## 功能概述

回收站用于临时存放已删除的应用与相关资源。如果不小心删除了某个应用，可以在回收站中查看并恢复；对于确认不再需要的项目，也可以在回收站中彻底清理，释放空间。

## 入口

在八爪鱼RPA 客户端左侧导航栏点击 **回收站** 即可进入。

## 页面结构

| 区域 | 说明 |
| --- | --- |
| 已删除项目列表 | 展示被删除的应用名称、删除时间等信息 |
| 恢复操作 | 将选中的应用还原到应用管理列表 |
| 彻底删除 | 永久删除选中的应用，删除后不可恢复 |

## 主要功能

### 恢复应用

选中回收站中的应用，点击「恢复」，该应用将重新回到应用管理界面的列表中，流程与配置保持不变。

### 彻底删除

对于确认不再需要的应用，选中后点击「彻底删除」，将从回收站中永久移除，释放相关资源。

## 使用流程

1. 进入「回收站」查看已删除的应用列表。
2. 找到需要恢复的应用，点击「恢复」。
3. 返回「应用管理界面」确认应用已还原。
4. 如需清理，选中应用后点击「彻底删除」。

<Info>
  彻底删除后的应用无法恢复，请谨慎操作。建议在删除重要应用前先导出或备份流程。
</Info>
