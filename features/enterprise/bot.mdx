## 功能概述

企业版机器人支持多成员、多任务并发执行。管理员可在企业后台统一管理机器人资源，将机器人分配给不同成员或任务，实现自动化流程的高效调度与负载均衡。

## 入口

切换到企业身份后，进入企业管理后台，选择 **机器人管理**。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 机器人列表 | 查看企业下所有机器人的状态、版本与归属 |
| 机器人分配 | 将机器人分配给指定成员或应用 |
| 并发调度 | 多个机器人可同时执行不同任务，提升整体吞吐 |
| 机器人详情 | 查看机器人 ID、运行记录等信息 |

## 使用流程

1. 管理员进入「机器人管理」查看企业机器人资源。
2. 根据业务需求将机器人分配给成员或应用。
3. 在触发器或 Webhook 中指定机器人运行应用。
4. 通过运行日志与企业控制台监控机器人任务执行情况。
