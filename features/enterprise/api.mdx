## 功能概述

八爪鱼RPA 提供开放 API 接口，支持企业将 RPA 能力集成到自身业务系统、内部平台或第三方应用中。通过 API Key 鉴权，可以实现应用列表查询、任务启动、结果获取等操作，无需人工登录客户端。

## 入口

在八爪鱼RPA 客户端左侧导航栏点击 **开放能力（AI）** → **API Key**，生成并管理调用凭证。

## 主要能力

| 能力 | 说明 |
| --- | --- |
| 应用管理 | 查询、创建、更新企业空间中的应用 |
| 任务调度 | 远程启动应用、获取任务状态与结果 |
| 机器人管理 | 查询机器人资源与状态 |
| 数据交互 | 在调用时传递输入参数，获取输出结果 |

## 鉴权方式

调用 API 时需在请求头中携带 API Key：

| Header 名称 | 示例值 |
| --- | --- |
| X-API-Key | `oct_wsqGD3xxxx` |
| Authorization | `Bearer oct_wsqGD3xxxx` |

## 使用流程

1. 在「开放能力（AI）」中创建 API Key 并妥善保存。
2. 阅读开放 API 接口文档，了解各接口地址与参数。
3. 在业务系统中调用接口，传递 API Key 与必要参数。
4. 根据返回结果处理应用启动、状态查询等逻辑。

<Info>
  API Key 等同于账号身份，请妥善保管，不要写入公开代码仓库。如怀疑泄露，请立即吊销并重新创建。
</Info>
