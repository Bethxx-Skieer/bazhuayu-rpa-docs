## 功能概述

企业空间是面向企业团队的自动化应用管理系统。通过企业空间，团队成员可以共享应用、协同编辑、追溯历史版本，并在统一的控制台中管理、监控和调度所有自动化流程。

## 入口

切换到企业身份后，在客户端左侧导航或企业管理后台进入 **企业空间**。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 应用共享 | 企业成员可在空间内查看、运行与编辑共享应用 |
| 流程版本管理 | 保存应用历史版本，便于回溯与恢复 |
| 流程管理/调度 | 管理员在控制台创建、管理、监控和调度自动化流程 |
| 协同编辑 | 多成员共同维护企业应用，提升开发效率 |

## 使用流程

1. 管理员在企业空间内创建或导入应用。
2. 设置应用的共享范围与成员权限。
3. 团队成员在企业空间中获取并使用共享应用。
4. 管理员通过控制台监控运行状态并统一调度任务。
