## 功能概述

成员管理用于管理企业内的成员账号、角色与权限。通过合理的权限配置，可以保障企业自动化资产安全，同时支持成员离职继承，避免流程与数据随人员变动而丢失。

## 入口

切换到企业身份后，进入企业管理后台，选择 **成员管理**。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 添加成员 | 通过邮箱邀请或协作码邀请新成员 |
| 角色配置 | 为成员分配管理员、开发者、使用者等不同角色 |
| 权限管理 | 控制成员对应用、机器人、触发器等资源的查看与操作权限 |
| 离职继承 | 成员离职后，其创建的应用与资源可继承给指定成员 |

## 使用流程

1. 企业管理员进入「成员管理」。
2. 点击「添加成员」，发送邀请链接或协作码。
3. 为新成员分配角色与权限。
4. 定期审核成员列表，及时处理离职与权限变更。
