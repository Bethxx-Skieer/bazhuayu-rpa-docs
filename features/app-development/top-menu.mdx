## 功能概述

顶部菜单栏位于流程编辑器的最上方，提供应用信息管理、文件操作、快捷工具与运行控制等高频功能，是流程开发过程中最常用的操作区域之一。

## 入口

进入任意应用的流程编辑界面，顶部横条即为顶部菜单栏。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 应用名称 | 点击可修改应用名称、简介与使用说明 |
| 保存 | 保存当前应用至云服务，换设备后也可查看 |
| 后退/前进 | 撤销或恢复上一步编辑操作 |
| 数据采集 | 快捷使用【数据采集】指令 |
| 浏览器 | 打开八爪鱼RPA 内置浏览器，用于捕获网页元素 |
| 运行应用 | 运行当前应用的主流程或当前子流程 |
| 帮助中心 | 跳转至八爪鱼RPA 帮助中心 |
| 工具箱 | 浏览器扩展程序、正则工具等辅助工具 |

## 工具箱

### 浏览器扩展程序

八爪鱼RPA 执行网页自动化时依赖浏览器扩展程序。使用 Chrome、Edge 等浏览器前，请先安装对应插件，否则运行时可能出现报错。

### 正则工具

用于测试、调试正则表达式，并可根据起止条件自动生成正则表达式，辅助文本匹配类流程开发。

## 使用流程

1. 在流程编辑器顶部查看或修改应用基本信息。
2. 编辑过程中随时点击「保存」防止进度丢失。
3. 需要捕获网页元素时，点击「浏览器」打开内置浏览器。
4. 完成编辑后点击「运行应用」进行调试。
