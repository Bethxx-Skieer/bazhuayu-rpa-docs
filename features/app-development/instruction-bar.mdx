## 功能概述

指令栏位于流程编辑器的左侧，集中展示八爪鱼RPA 提供的全部可用指令。用户可按分类浏览指令，也可通过搜索与收藏快速定位常用指令，再将其拖拽到中间流程栏完成流程搭建。

## 入口

进入任意应用的流程编辑界面，左侧纵向面板即为指令栏。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 分类浏览 | 按条件判断、循环、网页自动化、桌面自动化、Excel、操作系统、数据处理、AI 等类别展示指令 |
| 搜索指令 | 在顶部搜索框输入关键词，快速定位目标指令 |
| 收藏指令 | 将高频指令加入收藏，减少翻找时间 |
| 拖拽使用 | 选中指令后拖入中间流程栏，完成流程搭建 |

## 快捷跳转

指令栏顶部提供快捷跳转入口，可快速切换到常用分类：

- 条件判断
- 循环
- 网页自动化
- 桌面自动化
- Excel
- 操作系统
- 数据处理
- AI

![指令栏 - 分类与快捷跳转](images/Gc48az-21.png)

## 使用流程

1. 在流程编辑器左侧展开目标指令分类。
2. 通过搜索或收藏找到需要的指令。
3. 将指令拖拽到中间流程栏的合适位置。
4. 选中指令，在右侧参数栏配置具体参数。
