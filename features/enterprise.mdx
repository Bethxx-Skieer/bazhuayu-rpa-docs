## 功能概述

企业版功能面向团队协作与规模化自动化场景，在免费版基础上提供多成员协同、企业空间、机器人并发、Webhook 触发器、流程版本管理、私有化部署等能力，帮助企业高效管理自动化资产与任务调度。

## 免费版与企业版主要区别

| 功能 | 免费版 | 企业版 |
| --- | --- | --- |
| 成员数 | 1 | 3 - 6（可增购） |
| 机器人 | - | 3 - 6（可增购） |
| Webhook 触发器 | - | ✔ |
| 成员管理 | - | ✔ |
| 协作者管理 | - | ✔ |
| 企业空间 | - | ✔ |
| 流程版本管理 | - | ✔ |
| 流程管理/调度 | - | ✔ |
| 私有化部署 | - | 可增购 |

## 使用流程

1. 企业管理员创建企业并邀请成员加入。
2. 在企业空间中创建、分享与管理自动化应用。
3. 配置成员角色与权限，保障企业数字资产安全。
4. 通过机器人、触发器与 Webhook 实现任务调度与系统集成。
