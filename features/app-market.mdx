## 功能概述

八爪鱼 RPA **应用市场** 是面向用户的一站式应用模板与解决方案平台。市场汇聚了 **400+ 可复用应用模板**，覆盖数据采集、跨境电商、国内电商、人事、运营、市场、财务、社媒、AI 等主流场景。用户无需从零搭建流程，即可通过「搜索 → 获取 → 填参 → 运行」的方式快速使用他人发布的应用；也可以将自己搭建的应用发布到市场，供团队或社区复用。

<Info>
  电脑端访问地址：https://rpa.bazhuayu.com/appstore
</Info>

## 入口

在八爪鱼 RPA 客户端左侧导航栏中点击 **应用市场** 即可进入。页面顶部提供搜索框与快捷筛选标签，左侧为场景分类目录，右侧按模块展示解决方案与应用卡片。

![应用市场首页](images/app-market-home.png)

## 页面结构

| 区域 | 说明 |
| --- | --- |
| 顶部搜索栏 | 输入应用名称或关键词，快速定位所需应用 |
| 快捷筛选标签 | 常用组合筛选，如「跨境精选应用」「亚马逊」等 |
| 左侧分类目录 | 按业务场景划分的应用分类，点击即可筛选 |
| 内容卡片区 | 按模块展示解决方案、热门应用、最新上架、免费应用等 |

## 内容模块

### 解决方案

**解决方案** 将多款相关应用组合成完整的工作流，帮助用户快速落地某一业务场景。例如：

- **人事 AI+RPA 提效解决方案**：自动完成简历聚合与 AI 初筛等人事全流程工作。
- **Reddit 舆情监控解决方案**：整合 Reddit 数据采集与飞书多维表格 / BI 看板，高效监控关键词与热门帖。
- **飞书+AI+RPA 电商解决方案**：跨系统操作并聚合飞书多维表格，打通通知、审批与协作。
- **账单自动下载解决方案**：跨平台抓取账单、自动清洗转换并对接旺店通 / 金蝶等软件。

点击卡片可查看方案详情及包含的应用列表。

### 热门应用 / 最新上架 / 免费应用

- **热门应用**：按使用量与热度排序，优先展示高价值、高复用应用。
- **最新上架**：展示近期新发布的应用，便于第一时间体验新能力。
- **免费应用**：可免费获取使用的应用，适合快速验证与轻量场景。

每个应用卡片通常展示：应用名称、一句话说明、能力标签、发布者、运行次数与上架时间。

## 应用分类

左侧分类目录覆盖以下主要场景：

| 分类 | 典型用途 |
| --- | --- |
| 数据采集 | 网页 / 桌面数据采集、结构化导出 |
| 跨境电商 | 亚马逊、Shopee 等平台的 Listing 监控、跟卖监控、ASIN 巡检 |
| 国内电商 | 淘宝、京东、拼多多等平台的商品 / 订单 / 评价操作 |
| 人事 | 招聘、简历筛选、自动打招呼、考勤 |
| 运营 | 内容发布、账号管理、数据监控 |
| 市场 | 舆情监控、竞品分析、线索获取 |
| 财务 | 账单下载、发票处理、对账 |
| 社媒 | 小红书、抖音、微博、YouTube 等平台运营 |
| AI | 结合大模型、OCR 的智能处理与判断类应用 |

点击分类后，右侧会筛选出对应场景下的应用；也可组合使用顶部搜索框进一步缩小范围。

## 使用流程

1. **搜索或浏览**：通过顶部搜索框输入关键词，或在左侧选择业务分类。
2. **查看详情**：点击应用 / 解决方案卡片，阅读使用说明、参数要求与运行效果。
3. **获取应用**：根据页面提示将应用获取到自己的应用列表。
4. **填写参数**：在运行前填写必要的账号、URL、文件路径、关键词等参数。
5. **运行应用**：点击运行，机器人按照既定流程自动执行。

## 提交需求与定制开发

如果市场内没有符合自身业务的应用，可以点击页面中的 **提交需求**，或访问 [八爪鱼 RPA 高级开发者为你开发应用](https://skieer.feishu.cn/docx/S6hYdBaZRorzHQxTUYlcwc14nHh) 提交定制需求，由高级开发者按需开发。

## 发布应用

八爪鱼 RPA 支持将自己搭建的应用发布到应用市场，供其他用户或团队成员获取使用。发布前建议确认：

- 应用流程已在本地调试通过，运行结果稳定。
- 必填参数、选填参数与使用说明清晰完整。
- 涉及账号、密码、Cookie 等敏感信息的部分已使用变量或参数化方式处理，避免硬编码。
