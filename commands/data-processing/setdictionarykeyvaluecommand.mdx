## 指令说明

**描述：** 在字典中设置一对键值，若键名存在则修改值

## 参数说明

<Tabs>
  <Tab title="常规">
    ![写入数据到字典指令参数面板](images/setdictionarykeyvaluecommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **字典** | 输入字典变量 |
    | **键名** | 输入键名 |
    | **值** | 输入键值 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>
