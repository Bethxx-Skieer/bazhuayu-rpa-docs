title: "合并列表"

## 指令说明

**描述：** 将两个列表按先后顺序合并为一个新列表，并将合并结果保存到指定变量中。

## 参数说明

<Tabs>
  <Tab title="常规">
    ![合并列表指令参数面板](images/concatlistcommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **列表1** | 输入列表变量 |
    | **列表2** | 输入列表变量 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

![合并列表使用示例 - 流程搭建](images/concatlistcommand-02.png)

**该流程执行逻辑：**

1. 新建空列表，并将其保存为变量 **列表1**。
2. 在 **列表1** 的末尾插入数据 `Hello`。
3. 再新建空列表，并将其保存为变量 **列表2**。
4. 在 **列表2** 的末尾插入数据 `八爪鱼RPA`。
5. 合并 **列表1** 和 **列表2**，并将合并后的新列表保存为变量 **合并列表**。
