## 指令说明

**描述：** 将文本类型的数字转换为数值类型

## 参数说明

<Tabs>
  <Tab title="常规">
    ![文本转换为数值指令参数面板](images/texttonumbercommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **要转换的文本** | 输入一个仅包含数值的字符串或文本变量，用于转换为数值变量。空格将被忽略，出现非数值文本将会报错 |
    | **保存数值至** | 将装换后的数值保存到变量 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>
