## 指令说明

**描述：** 将对象转为Json文本

## 参数说明

<Tabs>
  <Tab title="常规">
    ![对象转json文本指令参数面板](images/objecttojsoncommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **对象** | 输入一个对象 |
    | **结果保存至** | Json文本 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

![对象转json文本使用示例 - 流程搭建](images/objecttojsoncommand-02.png)

**该流程执行逻辑：**

使用【文本转为Json对象】将文本`{"name":"八爪鱼RPA","age":18,"class":"文本转为Json对象"}`转换成Json对象，并将对象保存到Json对象

使用【对象转json文本呢】将Json对象，转为Json文本，并保存到Json文本
