**流程**类指令负责自动化流程的宏观控制，包括流程的启动、暂停、终止、子流程调用和异常处理。

## 指令能做什么

- **调用子流程**：在一个流程中调用另一个已发布的流程，实现模块化复用
- **终止流程**：在特定条件下主动结束当前流程的执行
- **异常处理**：设置错误捕获与重试机制，保证流程稳定运行
- **日志输出**：记录流程运行过程中的关键信息，便于排查问题

## 典型场景

| 场景 | 说明 |
| --- | --- |
| 模块复用 | 将登录逻辑封装为子流程，多个流程统一调用 |
| 容错机制 | 某步骤失败时自动重试 3 次，仍失败则发送通知并终止 |
| 流程编排 | 按顺序串联多个子流程完成复杂业务场景 |
