## 指令说明

**描述：** 通过该指令建立钉钉表格连接，以实现钉钉表格自动化

## 参数说明

<Tabs>
  <Tab title="常规">
    ![连接钉钉表格指令参数面板](images/connecttodingtalkspreadsheetcommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **AppKey** | 登录钉钉开发者后台，创建应用或使用已创建过的应用，获取此参数，详细步骤可见钉钉在线表格指令表格 |
    | **AppSecret** | 登录钉钉开发者后台，创建应用或使用已创建过的应用，获取此参数，详细步骤可见使用文档钉钉在线表格指令表格 |
    | **用户ID** | 登录钉钉管理后台，在成员管理模块获取，详细步骤可见使用文档钉钉在线表格指令表格 |
    | **表格ID** | 在钉钉表格页面，可通过左上角表格>文档信息获取，详细步骤可见使用文档钉钉在线表格指令表格 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

![连接钉钉表格使用示例 - 流程搭建](images/connecttodingtalkspreadsheetcommand-02.png)

**该流程执行逻辑：**

1. 在【连接钉钉表格】中填写授权信息和目标表格地址，建立表格连接。
2. 将生成的钉钉表格对象保存到变量。
3. 示例把该对象传给【读取表格数据】，读取指定单元格或区域，验证连接可以正常用于后续操作。
