**条件判断**类指令帮助你根据数据或页面状态自动选择执行路径，让流程具备"判断力"。

## 指令能做什么

- **IF 条件判断**：根据变量值、页面元素状态、文本内容等条件决定执行哪个分支
- **多条件判断**：支持多个条件组合判断（且/或），实现复杂的业务逻辑
- **分支跳转**：满足不同条件时执行对应的指令块

## 典型场景

| 场景 | 说明 |
| --- | --- |
| 数据校验 | 判断提取的数据是否为空，为空则重试或跳过 |
| 状态识别 | 根据页面状态（登录/未登录、有数据/无数据）走不同处理流程 |
| 业务规则 | 金额大于某值审批、库存低于阈值补货等业务逻辑 |
