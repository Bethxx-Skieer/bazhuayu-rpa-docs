---
title: "循环"
description: "重复执行相同的操作步骤，批量处理列表数据或循环等待条件满足。"
---

**循环**类指令让流程按照指定规则反复执行一组操作，是批量自动化任务的核心支撑。

## 指令列表

<CardGroup cols="2">
  <Card title="条件循环" href="/commands/loop/whilecommand">
    满足条件时持续循环执行内部指令块，直到条件不再成立。
  </Card>
  <Card title="按次数循环" href="/commands/loop/loopbycountcommand">
    指定循环次数，重复执行内部指令块指定次数。
  </Card>
  <Card title="列表循环" href="/commands/loop/foreachcommand">
    遍历列表中的每一项，依次取出元素进行处理。
  </Card>
  <Card title="字典循环" href="/commands/loop/dictionaryforeachcommand">
    遍历字典中的每个键值对，依次取出键和值进行处理。
  </Card>
  <Card title="无限循环" href="/commands/loop/infiniteloopcommand">
    无限重复执行内部指令块，需配合跳出/结束指令终止。
  </Card>
  <Card title="继续循环" href="/commands/loop/continuecommand">
    跳过本次循环剩余步骤，直接进入下一次循环。
  </Card>
  <Card title="跳出循环" href="/commands/loop/breakcommand">
    立即终止当前所在循环，跳出循环体继续执行后续指令。
  </Card>
  <Card title="结束循环" href="/commands/loop/endloopcommand">
    标记循环块的结束，与循环开始指令配对使用。
  </Card>
  <Card title="循环相似元素(web)" href="/commands/loop/web_loopsimilarelementscommand">
    自动识别网页中的相似元素列表并逐项循环操作。
  </Card>
  <Card title="循环相似元素(win)" href="/commands/loop/win_loopsimilarelementscommand">
    自动识别桌面窗口中的相似元素列表并逐项循环操作。
  </Card>
  <Card title="循环数据表格" href="/commands/loop/loopdatasheetcommand">
    循环遍历数据表格的每一行，逐行取出数据供后续指令使用。
  </Card>
</CardGroup>
