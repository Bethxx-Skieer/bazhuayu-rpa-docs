---
title: "数据库"
description: "连接主流关系型数据库，执行 SQL 查询与数据写入。"
---
**数据库**类指令让 RPA 流程直接连接数据库，执行数据查询、插入更新等操作，实现数据持久化存储。

## 指令能做什么

- **连接数据库**：支持 MySQL、SQL Server 等主流关系型数据库
- **执行 SQL**：执行 SELECT、INSERT、UPDATE、DELETE 等 SQL 语句
- **查询数据**：查询数据库并将结果集导入数据表格
- **批量插入**：将数据表格内容批量写入数据库
- **关闭连接**：操作完成后释放数据库连接

## 典型场景

| 场景 | 说明 |
| --- | --- |
| 数据归档 | 定期将业务系统中的历史数据提取并写入数据仓库 |
| 报表查询 | 从数据库查询经营指标，生成报表后发送群通知 |
| 批量导入 | 将 Excel 中的批量数据导入数据库 |
## 适用场景

- **业务数据读写**：用 连接数据库 / 执行SQL语句 / 查询数据库 读取业务库数据参与流程，或回写处理结果。
- **批量入库**：采集/计算得到的海量结果用 数据库批量插入数据 一次性写入，避免逐条慢写。
- **资源释放**：流程结束用 关闭数据库 释放连接，避免连接泄露。
