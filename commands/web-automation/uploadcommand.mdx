## 指令说明

**描述：** 自动完成点击上传按钮、在文件选择对话框中输入待上传文件等系列操作。

## 参数说明

<Tabs>
<Tab title="常规">
    ![上传文件指令参数面板](images/web-upload-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **网页对象** | 选择上传文件所在的网页对象 |
    | **上传按钮** | 选择触发上传操作的上传按钮元素 |
    | **文件路径** | 输入要上传的文件的完整路径 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

**该流程执行逻辑：**

使用【打开网页】指令打开目标网页

使用【上传文件】指令选择上传按钮和待上传文件

自动执行点击上传按钮、选择文件、确认上传等操作

![上传文件使用示例 - 流程搭建](images/web-upload-02.png)
