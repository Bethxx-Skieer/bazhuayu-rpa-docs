## 指令说明

**描述：** 主要用于少数无法直接捕获到的网页元素，可通过捕获其父元素、子元素、相邻元素来关联获取。

## 参数说明

<Tabs>
<Tab title="常规">
    ![获取相关元素指令参数面板](images/web-relative-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **网页对象** | 选择要操作的目标元素所在的网页对象 |
    | **参考元素** | 选择一个已捕获的元素作为参考 |
    | **关联方式** | 下拉选择：父元素、子元素、前一个兄弟元素、后一个兄弟元素 |
  </Tab>
  <Tab title="高级">
    | 参数 | 说明 |
    | --- | --- |
    | **筛选条件** | 可选，通过CSS选择器筛选关联元素，如按标签名、class等筛选 |
  </Tab>
</Tabs>

## 使用示例

![获取相关元素使用示例 - 流程搭建](images/web-relative-02.png)

**该流程执行逻辑：**

使用【打开网页】指令打开目标网页

捕获一个可定位的参考元素

使用【获取相关元素】指令选择关联方式，获取无法直接捕获的目标元素

一般和【循环相似元素】一起配合使用
