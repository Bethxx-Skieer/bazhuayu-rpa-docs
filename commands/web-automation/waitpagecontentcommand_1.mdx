## 指令说明

**描述：** 在指定的时间内，等待网页内容出现。

## 参数说明

<Tabs>
<Tab title="常规">
    ![等待网页内容指令参数面板](images/web-wait-content-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **网页对象** | 选择一个之前通过【打开网页】或【获取已打开的网页对象】指令创建的网页对象 |
    | **等待网页是否** | 包含元素、不包含元素、包含文本、不包含文本 |
    | **选择元素** | 从元素库中选择一个已捕获的元素或通过「捕获新元素」来捕获新的网页元素作为操作目标；文本：直接输入文本或选择文本变量 |
    | **设置超时时间** | 设置超时时间，单位为秒，超时后流程将终止流程或忽略异常并继续执行或重设此指令 |
    | **等待结果** | 在超时时间内，等待状态符合则返回变量值 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

**该流程执行逻辑：**

【打开网页】打开目标网页

【鼠标悬停在网页元素上】鼠标悬停在指定元素上触发下拉菜单

【等待网页内容】指令等待目标元素出现

【点击网页元素】若在超时时间内出现则点击目标元素

![等待网页内容使用示例 - 流程搭建](images/web-wait-content-02.png)

### 运行结果

在超时时间内检测到目标内容出现后，流程继续执行后续操作。
