## 指令说明

**描述：** 设置下拉框选项，仅支持HTML源码中<select>标签的下拉框。

## 参数说明

<Tabs>
<Tab title="常规">
    ![设置下拉框(web)指令参数面板](images/web-select-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **网页对象** | 选择要操作的目标元素所在的网页对象 |
    | **选择元素** | 选择目标下拉框（select元素），可通过「捕获新元素」来捕获 |
    | **选择方式** | 下拉选择：按选项文本选择、按选项值选择、按选项索引选择 |
    | **选项内容** | 根据选择方式，输入选项文本/选项值/选项索引 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

**该流程执行逻辑：**

使用【打开网页】指令打开目标网页

使用【设置下拉框(web)】指令捕获下拉框元素

选择下拉框的目标选项（按文本/值/索引）

![设置下拉框(web)使用示例 - 流程搭建](images/web-select-02.png)
