## 指令说明

**描述：** 获取网页监听的结果。

## 参数说明

<Tabs>
<Tab title="常规">
    ![获取网页监听结果指令参数面板](images/web-monitor-get-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **网页对象** | 选择正在监听的网页对象 |
    | **结果类型** | 选择要获取的结果类型 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

![获取网页监听结果使用示例 - 流程搭建](images/web-monitor-get-02.png)

**该流程执行逻辑：**

在【开始监听网页请求】和网络操作之后

使用【获取网页监听结果】指令获取监听到的网络请求数据

将结果保存至变量或输出到数据表格
