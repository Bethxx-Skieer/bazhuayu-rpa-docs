## 指令说明

**描述：** 获取网页中下拉框的选项，仅支持<select>标签下拉框。

## 参数说明

<Tabs>
<Tab title="常规">
    ![获取下拉框选项(web)指令参数面板](images/web-select-opt-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **网页对象** | 选择要操作的网页对象 |
    | **选择元素** | 选择目标下拉框（select元素），可通过「捕获新元素」来捕获 |
    | **获取方式** | 下拉选择：获取所有选项文本、获取所有选项值 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

**该流程执行逻辑：**

使用【打开网页】指令打开目标网页

使用【获取下拉框选项(web)】指令捕获下拉框元素

获取下拉框中所有选项的文本或值，以列表形式保存

![获取下拉框选项(web)使用示例 - 流程搭建](images/web-select-opt-02.png)
