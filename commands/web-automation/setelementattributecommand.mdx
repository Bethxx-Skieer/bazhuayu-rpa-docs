## 指令说明

**描述：** 用于在网页自动化过程中设置/修改目标元素的属性值，可用于表单填充、状态切换、样式调整等场景。

## 参数说明

<Tabs>
<Tab title="常规">
    ![设置网页元素属性指令参数面板](images/web-set-attr-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **网页对象** | 选择要操作的目标元素所在的网页对象 |
    | **选择元素** | 选择要设置属性的目标元素 |
    | **属性名** | 输入要设置的属性名称，如 value、class、style 等 |
    | **属性值** | 输入要设置的属性值 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

![设置网页元素属性使用示例 - 流程搭建](images/web-set-attr-02.png)

**该流程执行逻辑：**

使用【打开网页】指令打开目标网页

使用【设置网页元素属性】指令选择目标元素

设置元素的属性名和属性值，完成属性修改

### 运行结果

目标元素的属性值被成功修改。
