## 指令说明

**描述：** 根据目标文本，自动生成对应的文本摘要

## 参数说明

<Tabs>
  <Tab title="常规">
    ![文本摘要指令参数面板](images/makeasummarycommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **AI引擎** | OpenA |
    | **文本内容** | 输入要目标文本内容 |
    | **返回结果保存至** | 将提取的关键词保存到字符串变量 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>
