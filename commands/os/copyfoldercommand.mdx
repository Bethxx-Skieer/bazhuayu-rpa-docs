## 指令说明

**描述：** 将文件夹复制到目标文件夹中

## 参数说明

<Tabs>
  <Tab title="常规">
    ![复制文件夹指令参数面板](images/copyfoldercommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **文件夹路径** | 输入要复制的文件夹路径 |
    | **目标文件夹** | 将在此文件夹中粘贴复制的文件夹 |
    | **当文件存在时** | 当文件夹中已经存在同名的文件夹时可选择不执行复制操作、自动添加后缀或覆盖文件夹。注: 覆盖文件夹，如果被覆盖文件夹中的文件与覆盖文件夹中的文件不重名，则会被保留 |
    | **生成的变量** | 将粘贴后的文件夹路径保存至此变量若不存在则自动创建 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例


![复制文件夹使用示例](images/copyfoldercommand-03.png)

![复制文件夹使用示例 - 流程搭建](images/copyfoldercommand-02.png)

**该流程执行逻辑：**

1. 在【复制文件夹】中选择源文件夹 `D:/New教程`，并将目标位置设置为 `D:/八爪鱼下载`。
2. 根据目标文件夹已存在时的配置决定覆盖、合并或报错方式。
3. 运行后，源文件夹保持不变，目标目录中生成一份包含相同内容的文件夹副本。
