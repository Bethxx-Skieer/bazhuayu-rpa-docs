## 指令说明

**描述：** 把文件移动到指定文件夹

## 参数说明

<Tabs>
  <Tab title="常规">
    ![移动文件指令参数面板](images/movefilecommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **文件路径** | 输入要复制的文件路径 |
    | **目标文件夹** | 输入目标文件夹路径 |
    | **当文件存在时** | 指定当目标文件夹下已存在同名文件时要执行的操作，覆盖原有文件、不做任何处理、自动重命名 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>
