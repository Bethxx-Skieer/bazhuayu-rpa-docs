## 指令说明

**描述：** 将文本内容/文件(包括图片)添加到剪切板中，文件可实现快捷发送

## 参数说明

<Tabs>
  <Tab title="常规">
    ![添加内容到剪切板指令参数面板](images/setclipboarddatacommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **添加内容类型** | 文件名/文件 |
    | **文本内容** | 输入要放入剪切板中文的本内容 |
    | **文件路径** | 输入要添加到剪切板的文件路径 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

![添加内容到剪切板使用示例 - 流程搭建](images/setclipboarddatacommand-02.png)

**该流程执行逻辑：**

使用【添加内容到剪切板】命令将文本“八爪鱼教程内容”添加到剪切板

使用【获取剪切板文本】获取当前剪切板的文本，并放到变量剪切板文本

使用【打印日志】打印该变量，打印结果为：八爪鱼教程内容
