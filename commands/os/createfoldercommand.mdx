## 指令说明

**描述：** 创建文件夹

## 参数说明

<Tabs>
  <Tab title="常规">
    ![创建文件夹指令参数面板](images/createfoldercommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **父文件夹目录** | 输入或选择要在其中创建新文件夹的文件夹路径 |
    | **新文件夹名称** | 输入要创建的文件夹名称 |
    | **生成的变量** | 保存新文件夹路径变量 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>
