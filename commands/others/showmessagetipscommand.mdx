## 指令说明

**描述：** 显示消息提示信息

## 参数说明

<Tabs>
  <Tab title="常规">
    ![显示消息通知指令参数面板](images/showmessagetipscommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **消息类型** | 选择弹出消息的类型，成功、警告、异常、信息 |
    | **消息位置** | 选择弹出消息的位置，顶部、底部、右下 |
    | **消息窗口内容** | 输入要显示消息的内容文本 |
    | **关闭超时时间** | 设置关闭超时时间 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>
