## 指令说明

**描述：** 显示消息提示信息

## 参数说明

<Tabs>
  <Tab title="常规">
    ![显示消息通知指令参数面板](images/showmessagetipscommand-05.png)

    | 参数 | 说明 |
    | --- | --- |
    | **消息类型** | 选择弹出消息的类型，成功、警告、异常、信息 |
    | **消息位置** | 选择弹出消息的位置，顶部、底部、右下 |
    | **消息窗口内容** | 输入要显示消息的内容文本 |
    | **关闭超时时间** | 设置关闭超时时间 |
  </Tab>
  <Tab title="高级">
    ![显示消息通知高级参数面板](images/showmessagetipscommand-03.png)

    | 参数 | 说明 |
    | --- | --- |
    | **关闭超时时间(s)** | 设置消息通知自动关闭前的等待时间，单位为秒。 |
  </Tab>
</Tabs>

## 使用示例

![显示消息通知使用示例](images/showmessagetipscommand-01.png)

**该流程执行逻辑：**

1. 在【显示消息通知】中填写提示标题和消息内容，并选择“成功”通知级别。
2. 运行指令后，客户端在屏幕顶部显示成功提示框。
3. 该通知用于向用户反馈流程进度或执行结果，不会中断后续指令运行。
