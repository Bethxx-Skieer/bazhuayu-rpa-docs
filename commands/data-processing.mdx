---
title: "数据处理"
description: "对文本、数值、日期、JSON、正则等数据进行转换、提取和格式化处理。"
---
**数据处理**类指令提供丰富的数据转换与加工能力，是连接"采集"与"输出"之间的核心加工环节。

## 指令能做什么

- **字符串处理**：拼接、截取、替换、大小写转换、去除首尾空格
- **正则匹配**：通过正则表达式提取文本中的关键信息（电话号码、邮箱、URL 等）
- **类型转换**：文本与数值互转、日期格式化、JSON/XML 解析
- **编码解码**：Base64 编码解码、URL 编解码

## 典型场景

| 场景 | 说明 |
| --- | --- |
| 数据清洗 | 从网页抓取的杂乱文本中，用正则提取手机号、金额等关键字段 |
| 格式转换 | 将 "2024-08-16" 格式的日期转为 "2024年8月16日" |
| JSON 解析 | 调用 API 返回的 JSON 数据，提取指定字段写入数据表格 |
## 适用场景

- **文本清洗与转换**：用 去除空格 / 文本替换 / 拆分文本 / 截取文本 / 改变大小写 规整脏数据。
- **数值与时间处理**：数值文本互转、日期格式统一、计算时间差、时间戳与日期互转。
- **正则提取**：用 正则匹配 / 文本替换(正则替换) 从日志、网页源码中抠出手机号、邮箱、价格等。
- **列表/字典容器操作**：新建/合并/去重/排序列表，字典读写键值，支撑复杂数据流转。
- **JSON/URL 编解码**：文本与 Json 对象互转、URL 编解码，方便和接口数据对接。
