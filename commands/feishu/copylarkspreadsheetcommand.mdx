## 指令说明

**描述：** 拷贝飞书表格中指定的Sheet页

## 参数说明

<Tabs>
  <Tab title="常规">
    ![拷贝飞书表格指令参数面板](images/copylarkspreadsheetcommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **飞书电子表格** | 选择需要读取的飞书电子表格 |
    | **新Sheet页名称** | 输入新飞书电子表格Sheet页的名称（未存在的Sheet页名称） |
    | **生成的变量** | 保存新表格对象变量 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

![拷贝飞书表格使用示例 - 流程搭建](images/copylarkspreadsheetcommand-02.png)

**该流程执行逻辑：**

获取飞书访问凭证，并将其保存至"飞书访问凭证"中--->根据网址获取飞书表格，并将结果保存至"飞书电子表格"中--->

使用[拷贝飞书表格]对飞书电子表格进行拷贝，并将新的Sheet页命名为Sheet2，保存表格对象至"飞书电子表格_副本"
