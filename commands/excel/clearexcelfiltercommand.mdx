## 指令说明

**描述：** 清除Excel工作表中设置的筛选条件，恢复显示所有数据。

## 参数说明

<Tabs>
  <Tab title="常规">
    ![清除筛选条件指令参数面板](images/clearexcelfiltercommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **Excel对象** | 请选择Excel对象（可通过指令【启动Excel】或【获取当前激活的Excel对象】创建），用于确定待操作的工作簿。 |
    | **Sheet页名称** | 操作目标工作表的名称，支持选填，默认为当前Excel激活的Sheet页。 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

## 使用示例

![清除筛选条件使用示例 - 流程搭建](images/clearexcelfiltercommand-02.png)

**该流程执行逻辑：**

使用【启动Excel】打开已有的Excel，并将Excel对象保存到excel对象

使用【Excel筛选】指令筛选指定数据

使用【读取筛选内容】指令读取筛选后内容

使用【清除筛选条件】指令恢复全部数据显示
