## 指令说明

**描述：** 设置Excel工作表的行高和列宽。

## 参数说明

<Tabs>
  <Tab title="常规">
    ![设置行高/列宽指令参数面板](images/setexcelcellsizecommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **Excel对象** | 请选择Excel对象（可通过指令【启动Excel】或【获取当前激活的Excel对象】创建），用于确定待操作的工作簿。 |
    | **Sheet页名称** | 操作目标工作表的名称，支持选填，默认为当前Excel激活的Sheet页。 |
    | **设置类型** | 下拉选择：行高、列宽 |
    | **行号/列号** | 输入需要设置的行号或列号。 |
    | **高度/宽度** | 输入行高或列宽的具体数值。 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>

使用【设置行高/列宽】指令设置指定行或列的尺寸
