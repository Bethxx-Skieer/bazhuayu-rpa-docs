**指令**是八爪鱼 RPA 流程搭建的基本单元，每个指令对应一个具体的自动化操作。

## 指令分类概览

<CardGroup cols="2">
  <Card title="浏览器指令">
    页面跳转、元素点击、表单填写、数据提取等浏览器自动化相关指令。
  </Card>
  <Card title="数据处理指令">
    变量读写、字符串处理、正则匹配、JSON/XML 解析等。
  </Card>
  <Card title="流程控制指令">
    条件判断、循环、等待、异常处理等流程逻辑控制。
  </Card>
  <Card title="系统操作指令">
    文件读写、剪贴板、键盘模拟、窗口操作等系统级指令。
  </Card>
  <Card title="AI 指令">
    大模型调用、OCR 识别、验证码识别等人工智能相关指令。
  </Card>
  <Card title="应用集成指令">
    Excel 操作、数据库连接、HTTP 请求、邮件发送等第三方集成。
  </Card>
</CardGroup>
