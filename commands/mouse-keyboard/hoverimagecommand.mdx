## 指令说明

**描述：** 在指定范围内查找图像并将鼠标移动到图像上。

## 参数说明


<Tabs>
  <Tab title="常规">


    ![鼠标悬浮在图像上指令参数面板](images/hoverimagecommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **搜索范围** | 查找目标图像的范围，可选：整个屏幕、窗口对象或当前激活窗口 |
    | **选择图像** | 选择已存在的图像，或捕获新图像 |
  </Tab>
  <Tab title="高级">


    ![鼠标悬浮在图像上高级参数面板](images/hoverimagecommand-02.png)

    | 参数 | 说明 |
    | --- | --- |
    | **光标位置** | 请选择光标偏移的起点，默认为图像中 |
    | **相似度** | 指定目标图像与原始图像的相似程度，推荐相似度为 80% |
    | **匹配模式** | 查找图像的匹配方式，彩色匹配相对灰度匹配更加精确 |
    | **执行后延时** | 指令执行后，执行下一个指令前的等待时间 |
    | **超时时间** | 设置执行此指令的最大等待时间 |
    | **横向偏移量（px）** | 输入 10 表示将光标从光标位置开始右移 10px，-10 则表示左移 10px |
    | **纵向偏移量（px）** | 输入 10 表示将光标从光标位置开始下移 10px，-10 则表示上移 10px |
  </Tab>
</Tabs>

## 使用示例


![鼠标悬浮在图像上使用示例](images/hoverimagecommand-05.png)

![鼠标悬浮在图像上使用示例](images/hoverimagecommand-07.png)

**该流程执行逻辑：**

1. 使用“捕获新图像”截取页面中的“手机/运营商/数码”区域，并将该图像设置为查找目标。
2. 在【鼠标悬浮在图像上】中设置整个屏幕为搜索范围，并按需要配置匹配相似度和超时时间。
3. 运行后，指令找到目标图像并将鼠标移动到图像位置，使页面触发对应的悬浮状态。
