## 指令说明

**描述：**设置窗口是否显示。

## 参数说明

![设置窗口是否显示指令参数面板](images/setwindowvisibilitycommand-01.png)

| 参数 | 说明 |
| --- | --- |
| **获取窗口方式** | 选择获取窗口方式，窗口对象、窗口标题或类型名、捕获窗口元素 |
| **窗口对象** | 输入一个通过"获取窗口对象"获取的窗口对象 |
| **窗体可见性** | 对窗口选择设置：显示窗口、隐藏窗口 |

## 使用示例

使用【获取窗口对象】获取指定的窗口对象 → 使用【设置窗口是否显示】设置窗口为显示或隐藏状态。
