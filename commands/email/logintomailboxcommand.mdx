## 指令说明

**描述：** 填写邮箱信息，用于登录邮箱

## 参数说明

<Tabs>
  <Tab title="常规">
    ![登录邮箱指令参数面板](images/logintomailboxcommand-01.png)

    | 参数 | 说明 |
    | --- | --- |
    | **邮箱类型** | QQ邮箱、163邮箱、126邮箱、腾讯企业邮箱、网易企业邮箱、Outlook、谷歌邮箱、自定义邮箱 |
    | **用户名** | 填入要登录的邮箱的用户名 |
    | **密码/授权码** | 密码：输入邮箱密码、 授权码：授权码的获取方式可参考 如何获取邮箱的登录配置信息 |
    | **使用SSL** | 勾选是否使用SSL，一般在具体的邮箱个人设置中配置 |
  </Tab>
  <Tab title="高级">
    本指令暂无高级参数。
  </Tab>
</Tabs>
