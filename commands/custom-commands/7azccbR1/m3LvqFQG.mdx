# 一.功能描述

该指令实现了登录千牛客户端的操作。
![image](images/m3LvqFQG-01.png)

# 二.使用说明
## 输入参数

<strong>千牛账号：</strong>

输入千牛登录账号。

<strong>千牛密码：</strong>

输入千牛登录密码。
## 输出参数：

<strong>登录状态：</strong>

成功返回true，失败返回false
![image](images/m3LvqFQG-02.png)

# 三、注意事项

该指令运行前需要执行以下几个步骤

1、进入八爪鱼RPA安装目录下，移动qt_whiteList文件，移动后重启八爪鱼RPA

文件下载链接：https://skieer.feishu.cn/file/J6mubIui5ooTmaxHGVfc2OA4nib
![image](images/m3LvqFQG-03.png)

2、适用于9.88.01N(1499,64)左右的版本，若发现不适配的情况，请重新安装千牛版本。

千牛设置需打开【启用讲述人模式】

![image](images/m3LvqFQG-04.png)
