# 一.功能描述

该指令实现了从千牛客户端获取当前客户的聊天记录。
![image](images/M4BVlWpx-01.png)

# 二.使用参数说明
## 输出参数：

返回采集的消息记录表。
![image](images/M4BVlWpx-02.png)

# 三.注意事项

该指令运行前需要执行以下几个步骤

1、进入八爪鱼RPA安装目录下，移动qt_whiteList文件，移动后重启八爪鱼RPA

文件下载链接：https://skieer.feishu.cn/file/J6mubIui5ooTmaxHGVfc2OA4nib

![image](images/M4BVlWpx-03.png)

2、适用于9.88.01N(1499,64)左右的版本，若发现不适配的情况，请重新安装千牛版本。

千牛设置需打开【启用讲述人模式】
![image](images/M4BVlWpx-04.png)
