title: "增加记录"

## 一、指令概述

用于向指定多维表格中新增一条记录，并返回新增记录的唯一 ID，适用于数据录入、业务流程数据同步等场景，可替代手动逐条录入的操作。
## 二、调用参数配置参数名称配置说明约束规则表格对象目标多维表格的对象（用于定位要新增记录的表格）可通过指令《通过授权码获取授权对象》获取必填；要添加的数据包含字段名与对应值的字典（单条记录），如\{"订单ID": "001", "金额": 100\}必填；键需与表格字段名完全匹配，值需符合字段数据类型要求生成的变量存储新增记录 ID 的变量名称必填；用于承接输出结果，供下游指令调用（如后续修改、查询操作）
三、输出说明<strong>输出类型定义</strong>：输出为<strong>字符串（单条记录）或字符串列表（多条记录）</strong>；<strong>输出核心内容</strong>：返回新增记录的唯一 ID
## 四、典型操作示例
示例：批量新增订单记录配置 “表格对象”：选择目标订单多维表格；配置 “要添加的数据”：输入字典：配置 “生成的变量”：命名为new_order_ids；执行指令后，new_order_ids变量存储新增订单的 ID 列表，可直接用于后续订单状态更新。
