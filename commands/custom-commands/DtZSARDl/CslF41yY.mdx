title: "修改记录"

## 一、指令概述

用于修改指定多维表格中对应记录 ID 的记录内容，支持按 ID 精准定位目标记录并更新其字段值，适用于数据维护、状态更新、信息修正等场景，可替代手动在表格中逐条修改的操作。
## 二、调用参数配置参数名称配置说明约束规则表格对象目标多维表格的对象（用于定位要修改的表格）必填；需为有效的多维表格对象，确保已完成权限配置数据 ID要修改的记录唯一标识（对应表格中每条记录的 ID）必填；需为目标表格中存在的有效记录 ID，否则修改失败要修改的值包含字段名与新值的字典（如\{"状态": "已完成", "备注": "已更新"\}）必填；键需与表格字段名完全匹配，值需符合字段数据类型要求
## 四、典型操作示例
示例：更新订单状态与备注配置 “表格对象”：选择目标订单多维表格 <strong>可通过指令《通过授权码获取授权对象》获取</strong>；配置 “数据 ID”：输入要修改的订单记录 ID（如"rec123456"）；配置 “要修改的值”：输入字典\{"订单状态": "已发货", "物流备注": "顺丰速运，单号SF123456"\}；执行指令后，该订单记录的状态与备注将被更新。
