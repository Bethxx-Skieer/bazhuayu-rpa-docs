# 一.功能描述

根据【文叔叔-上传文件】返回的下载链接下载文件。
![image](images/woOAdOgm-01.png)

# 二.使用说明
## 输入参数

<strong>文件链接：</strong>

请输入文件链接。

<strong>保存文件名：</strong>

输入保存文件名称，无需后缀名。

<strong>保存文件夹：</strong>

选择保存文件夹路径。
## 输出参数：

<strong>下载文件路径：</strong>

返回下载文件路径。
