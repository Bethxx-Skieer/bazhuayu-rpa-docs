# 描述
使用淘宝账号在mini网页登录淘宝个人后台界面![image](images/lXZmp9Cz-01.png)

## 配置
### 输入
#### 常规

<strong>浏览器类型: </strong>默认支持谷歌浏览器

<strong>账号: </strong><em>字符串, </em>输入登录的账号

<strong>密码: </strong><em>字符串, </em>输入登录的密码
