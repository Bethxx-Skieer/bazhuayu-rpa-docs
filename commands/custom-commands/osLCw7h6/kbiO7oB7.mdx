# <strong>生意参谋-交易-交易构成-</strong>终端构成<strong>数据-下载明细</strong>
# <strong>一.功能描述</strong>

用于 生意参谋-交易-交易构成-终端构成数据的获取
![image](images/kbiO7oB7-01.png)

# <strong>二.使用参数说明</strong>
## <strong>1.输入参数</strong>

<strong>网页对象：</strong> 传入已打开的网页对象。

<strong>适用的浏览器类型:</strong> Google Chrome浏览器

<strong>终端选择：</strong>

<strong>全部/PC/无线</strong>

<strong>日期类型：</strong> 下拉选择日期控件类型 支持：最近1天，最近7天，最近30天，自然日，自然周，自然月

<strong>日期：</strong> 若选择日、周请补充一个具体日期，格式：yyyy-mm-dd；如2025-01-01 若选择月请选择到月，格式：yyyy-mm；如2025-08

<strong>保存文件名：</strong>

输入保存文件的文件名。

<strong>保存文件夹：</strong>

输入保存文件的文件夹路径。
### <strong>高级</strong>
## <strong>无</strong>
## <strong>2.输出参数</strong>

<strong>下载文件路径：</strong>

输出下载后的文件绝对路径。
