## 一、指令概述

该 RPA 指令支持调用 GPT、谷歌 Gemini 模型，区分文生图、图生图两套独立逻辑批量出图。**文生图模式读取本地 CSV 配置文件（图号，提示词）批量绘图；图生图模式不使用 CSV，直接读取输入图片文件夹内参考图，搭配统一图生图提示词批量重绘**，支持指定图片输出保存目录、生图分辨率、图片比例；适配电商主图、POD 印花、文创手办拼图素材批量生产自动化流程。 <br />CSV 文件格式约定（仅文生图使用）：第一列为图号 / 文件名，第二列为生成图片的提示词，可通过 Excel 编辑表格后另存为 CSV 格式得到配置文件。生成图片直接落盘保存至结果保存文件夹，适合大批量素材批量产出，对接电商打版、商品图生成、素材库构建自动化流程。 <br />**重要限制**：CSV 仅文生图模式生效，图生图模式忽略 CSV 文件；图生图模式读取输入图片文件夹全部参考图，每张图共用一套统一附加提示词；生图尺寸仅支持 1k/2k/4k，图片比例仅支持预设列表内比例；单条任务失败不会中断整体流程。

## 二、参数配置说明

| 参数名称 | 示例 / 默认值 | 参数说明 |
| --- | --- | --- |
| GPT 生图模式 | 文生图 / 图生图 | 下拉选择 GPT 绘图模式，区分两套任务逻辑，联动控制【图生图提示词】控件是否展示。 |
| 谷歌 Gemini 生图模式 | 文生图 / 图生图 | 下拉选择 Gemini 绘图模式，独立于 GPT 模式，切换对应模型的绘图逻辑。 |
| 授权码 | 接口鉴权字符串 | 模型调用鉴权凭证，支持静态填写、变量传入，为空直接终止节点，不发起 API 请求。 |
| 提示词 csv 文件 | `D:\prompt\img_prompt.csv` | 仅【文生图模式】使用；CSV 配置文件完整路径；由 Excel 另存为 CSV 格式生成，格式：图号，提示词；图生图模式下该参数不生效、不读取。 |
| 输入图片文件夹 | `D:\ref_img\source` | 仅【图生图模式】必填，存放所有参考原图；文生图模式该参数不生效；目录不存在会校验失败。 |
| 结果保存文件夹 | `D:\output\ai_img` | 生成图片的输出目录；目录不存在指令自动创建；生成图片统一落盘保存到此目录。 |
| 生图尺寸 | 1k | 可选 1k、2k、4k；不同尺寸计费价格不同，按需选择，填写其他值校验失败。 |
| 生成图片比例 | 3:4 | 支持比例：1:1、16:9、9:16、4:3、3:4、3:2、2:3、5:4、4:5、21:9、9:21、1:3、3:1、2:1、1:2，不支持非标自定义比例。 |
| 图生图提示词 | 白底产品图，干净背景 | 仅图生图模式生效，统一附加提示词；文件夹内所有参考图都复用这套提示词；仅 GPT 生图模式选择【图生图】时展示，文生图模式自动隐藏。 |

CSV 文件示例（仅文生图使用，Excel 表格）

| 图号 | 提示词 |
| --- | --- |
| SKU001 | 生成一只可爱的小狗 |
| SKU002 | 生成一只可爱的小猫 |
| SKU003 | 一个小孩在放风筝 |

CSV 文本示例

```
SKU001,生成一只可爱的小狗
SKU002,生成一只可爱的小猫
SKU003,一个小孩在放风筝
```

输出说明： <br />文生图：图片按 CSV 第一列图号命名，例如 SKU001.png； <br />图生图：图片沿用原图文件名保存； <br />同时输出结构化 JSON 结果，包含任务编号、模型、模式、图号 / 原图路径、最终提示词、尺寸、比例、生成文件路径、任务状态、报错信息。

## 三、使用示例

### 适用场景

- 电商商品主图批量生产（文生图）：CSV 维护 SKU 与提示词，一次性批量生成大量商品效果图，快速扩充商品素材库。
- 产品原图批量重绘（图生图）：放入一批产品参考图，填写统一提示词，全部图片统一风格重绘，不需要逐个维护 CSV。
- POD 印花素材批量产出：CSV 维护多组图号和印花提示词，批量生成不同风格印花图案。
- 文创素材流水线：拼图、手办、铁皮画素材批量出图，对接后续图片理解、商品上架流程。

### 参数配置参考

## 四、执行流程

1. 校验授权码有效性；校验输出文件夹读写权限，不存在则自动创建。
2. 判断 GPT 生图模式分支： <br />**分支 A【文生图】** <br />①校验 CSV 文件是否存在，读取 CSV 全部行； <br />②循环读取 CSV 每一行：第一列为输出图号，第二列为绘图提示词； <br />③调用选中的 GPT 或 Gemini 绘图接口，按指定尺寸、比例绘图； <br />④图片以 CSV 图号命名保存至结果文件夹，生成单条任务 JSON 记录。 <br />**分支 B【图生图】** <br />①校验输入图片文件夹是否存在，读取文件夹内全部参考原图； <br />②循环遍历每一张参考原图，固定使用【图生图提示词】作为绘图指令； <br />③调用选中的 GPT 或 Gemini 绘图接口，传入原图 + 统一提示词，按指定尺寸、比例绘图； <br />④图片沿用原图文件名保存至结果文件夹，生成单条任务 JSON 记录； <br />⑤本分支不读取、不使用 CSV 文件。
3. 全部任务循环完成，指令结束，在输出目录查看全部生成图片。

## 五、运行效果

文生图：读取 CSV 内每一条 “图号，提示词” 记录，批量生成图片，按图号命名落盘； <br />图生图：遍历文件夹内所有参考图，共用同一套提示词批量重绘，沿用原图文件名； <br />总耗时随任务数量增加，受接口并发、网络速度影响。生成成功图片直接保存；失败条目跳过，记录报错信息，不会终止整个批量任务。

## 六、注意事项

1. 提前确认授权码有效、账户余额充足、对应模型接口权限已开通；授权码过期、欠费、权限缺失直接调用失败。
2. 计费规则：1k/2k/4k 不同尺寸单价不同，以模型官方计费规则为准；提示词违规、接口报错、网络失败不扣费。
3. 文生图 CSV 制作规范：Excel 编辑完成后另存为【CSV (逗号分隔)(*.csv)】；必须使用英文逗号分隔，禁止中文逗号；第一列图号禁止包含 / \ : * ? " < > | 等系统非法字符。
4. 图生图模式下，文件夹内所有图片统一使用同一个图生图提示词，无法给每张图单独设置提示词。
5. 输出目录同名文件会直接覆盖，建议每次使用全新输出文件夹，避免图片被覆盖丢失。
6. 全程需要联网，离线无法调用 AI 绘图接口；网络超时、接口限流会出现单条生成失败，程序继续执行下一条。
7. 生成图片版权风险由使用者自行承担，禁止生成侵权、违法违规内容。

## 七、延伸应用

1. 联动电商产品图片理解指令：先识别产品原图信息，导出 “图号，提示词” 格式 CSV，送入文生图分支批量生成图片；或者直接送入图生图分支，统一重绘。
2. 完整自动化流水线：图片理解提取产品信息 → 选择文生图 / 图生图分支批量出图 → 图片合规处理，实现电商素材自动化产出。
3. 两种模式灵活切换：同一节点，切换模式即可切换 “CSV 批量提示词” 和 “原图批量统一重绘” 两套逻辑，不用更换 RPA 节点。
4. 切换不同模型做效果对比：同一套素材 / CSV，分别调用 GPT、Gemini 生成不同版本，筛选更适合业务的出图效果。
