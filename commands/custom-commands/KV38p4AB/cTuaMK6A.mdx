# 最新外汇牌价查询
### 描述

数据来源中国银行官网，查询指定币种最新的外汇牌价信息(若查询结果为空，则表明检索不到对应信息)
### 配置项说明

常规

币种: 选择货币类型

价格类型: 选择查看的价格类型
