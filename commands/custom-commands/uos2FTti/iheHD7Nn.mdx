# 描述

输入指数x，返回自然常数e的x次方的值。
![image](images/iheHD7Nn-01.png)

# 配置说明
### 输入

<strong>x：</strong>输入参数x，类型必须为数字number。
### 输出

e的x次方幂的值<strong>：</strong>

输出自然常数e的x次方的值
