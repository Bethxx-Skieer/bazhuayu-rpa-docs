# <strong>一.功能描述</strong>

用于 生意参谋-服务-店铺绩效-售后分析数据的获取
![image](images/orT2LKYr-01.png)


# <strong>二.使用参数说明</strong>
## <strong>1.输入参数</strong>

<strong>网页对象：</strong> 传入已打开的网页对象。

<strong>适用的浏览器类型:</strong> Google Chrome浏览器

<strong>日期类型：</strong> 下拉选择日期控件类型 支持：昨天，7天，30天，日，月，自定义

<strong>日期：</strong> 若选择日请补充一个具体日期，格式：yyyy-mm-dd；如2025-01-01 若选择月请选择到月，格式：yyyy-mm；如2025-08若选择自定义请填写，开始日期和结束日期，格式：yyyy-mm-dd；如2025-01-01 <strong>(时间最大跨度92天)</strong>

<strong>售后分析类型：</strong>

输入根据页面内容获取。

<strong>售后退款类型：</strong>

输入根据页面内容获取。

<strong>保存文件名：</strong>

输入保存文件的文件名。

<strong>保存文件夹：</strong>

输入保存文件的文件夹路径。
### <strong>高级</strong>
## <strong>无</strong>
## <strong>2.输出参数</strong>

<strong>下载文件路径：</strong>

输出下载后的文件绝对路径。
