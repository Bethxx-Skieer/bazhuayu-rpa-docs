# Temu-结算数据-已到账数据导出
## 描述

该指令实现了对Temu的结算数据进行导出
![image](images/g1u0UHtu-01.png)

## 参数配置
### 指令输入

<strong>网页对象: </strong> 网页对象

账单类型：PO聚合账单、PO明细账单

交易类型：全选、销售回款、销售冲回、运费回款、运费冲回

<strong>开始日期：</strong>填写一个报表开始日期，YYYY-MM-DD

<strong>结束日期：</strong>填写一个报表结束日期，YYYY-MM-DD

<strong>保存文件夹：</strong>选择一个保存文件夹地址

<strong>保存文件名：</strong>自定义文件名称
### 指令输出

<strong>文件路径: </strong> 输出下载报表的文件路径
