# 描述

该指令实现营销-内容明细页面的时间选择功能
![image](images/H7LQO1XL-01.png)

# 配置项说明
## 指令输入
#### 网页对象：

任意一个已登录京东商智商家版后台营销-内容明细页面的网页对象
#### 时间查询方式：

下拉框，可选择：按天查询、按周查询、按月查询、近7天、近30天，选填，若不填则使用平台默认值
