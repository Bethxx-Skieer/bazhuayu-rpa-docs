# 描述

该指令实现获取实时-实时榜单页面全部渠道数据，并写入Excel保存到指定位置
![image](images/SevJDc9L-01.png)

# 配置项说明
## 指令输入
#### 网页对象：

任意一个已登录京东商智品牌版后台的网页对象

<strong>具体日期:</strong>

下拉框，可选：今日累计、昨日晚8累计

<strong>数据维度：</strong>

下拉框，可选：SPU维度、SKU维度

<strong>品牌:</strong>

数据类型:文本值列表，填写自己网页中展示的品牌名称,例如:["全部"]，支持多选
![image](images/SevJDc9L-02.png)

<strong>经营模式:</strong>

填写自己网页中展示的经营模式,例如:全部
![image](images/SevJDc9L-03.png)

一级终端类目名称：

输入具体类目。若选择一级类目，直接输入一级类目名称，例如：全部

二级终端类目名称：

输入具体类目。若选择二级类目，直接输入二级类目名称，例如：APP。类目名称需要与网站显示的名称一致，否则可能导致无法选择，二级终端类目名称选填
![image](images/SevJDc9L-04.png)

<strong>商品数据类型下载类型：</strong>

下拉框：商品浏览量TOP200、商品成交金额TOP200

<strong>自定义路径:</strong>

选择下载文件保存的文件夹路径，必填项
## 高级
#### 自定义文件名:

输入文件下载的名称，选填，若不填则使用平台默认名称
## 指令输出
#### 生成路径：

输出文本类型，下载的文件路径
