---
title: "批量图片裂变（裂变为不同 ip 元素）"
---

## 一、指令概述

批量对原图进行图片裂变，生成带有不同 IP 元素的新图案；成本低廉，单次要几分钱，1 小时最高可生成 4000-5000 张图片，适合跨境 POD、电商素材批量差异化出图。

## 二、输入参数

| 参数名称 | 参数类型 | 参数说明 |
| --- | --- | --- |
| 授权码 | 文本 | sk 开头授权码，注册可免费试用，用于接口鉴权 |
| 结果保存文件夹 | 文件夹路径 | 裂变完成后的图片存放目录 |
| 输入图片文件夹 | 文件夹路径 | 待进行 IP 元素裂变的原始图片存放目录 |
| 是否需要输出 png 格式图片 | 下拉选择 | 可选【是 / 否】，选择是则输出 PNG 透明图，否则默认其他格式 |

## 三、输出参数

| 参数名称 | 参数类型 | 参数说明 |
| --- | --- | --- |
| 成图结果 | 文本 / 文件夹对象 | 返回生成完成图片的结果信息，输出文件统一存放至【结果保存文件夹】 |

## 四、执行流程

1. 填入有效的 sk 开头授权码，完成接口鉴权；
2. 选择**输入图片文件夹**，系统读取文件夹内所有待处理原图；
3. 设置**结果保存文件夹**，指定裂变图片输出位置；
4. 选择是否输出 PNG 格式图片；
5. 启动指令，批量对每张原图裂变，自动替换生成不同 IP 元素图案；
6. 全部任务执行完成后，将生成图片存入目标文件夹，回传【成图结果】。

## 五、注意事项

- 授权码为 sk 开头，授权失效会直接导致任务执行失败；
- 输入文件夹内仅放入需要裂变的原图，不要混入无关文件；
- 大量批量生成时，建议预留足够磁盘空间用于存放成图；
- 任务并发上限受接口限制，最高 1 小时产出 4000-5000 张；
- 如需透明背景素材，将【是否需要输出 png 格式图片】设置为 “是”。
