---
title: "批量图片裂变（裂变为相同 IP 的相似图）"
---

## 一、指令概述

批量对原图进行图片裂变，在**保留同一个 IP 主体不变**的前提下生成大量相似变体图案；成本低廉，单次要几分钱，1 小时最高可生成 4000-5000 张图片，适合跨境 POD、电商素材批量扩图、同款素材多版本产出。

## 二、输入参数

| 参数名称 | 参数类型 | 参数说明 |
| --- | --- | --- |
| 授权码 | 文本 | sk 开头授权码，注册可免费试用，用于接口鉴权 |
| 输入图片文件夹 | 文件夹路径 | 待进行 IP 相似图裂变的原始图片存放目录 |
| 结果保存文件夹 | 文件夹路径 | 裂变完成后的相似图片存放目录 |
| 是否需要输出 png 格式图片 | 下拉选择 | 可选【是 / 否】，选择是则输出 PNG 图片，否则默认其他格式 |

## 三、输出参数

| 参数名称 | 参数类型 | 参数说明 |
| --- | --- | --- |
| 脚本输出 | 文本 | 返回任务执行状态、成图数量等结果信息，生成图片统一存放至【结果保存文件夹】 |

## 四、执行流程

1. 填入有效的 sk 开头授权码，完成接口鉴权；
2. 选择**输入图片文件夹**，系统读取文件夹内所有待处理原图；
3. 设置**结果保存文件夹**，指定相似图输出位置；
4. 选择是否输出 PNG 格式图片；
5. 启动指令，批量对每张原图裂变，保持 IP 主体不变，生成多张风格 / 细节有差异的相似图；
6. 全部任务执行完成后，生成图片存入目标文件夹，回传【脚本输出】结果信息。

## 五、注意事项

- 授权码为 sk 开头，授权过期或填写错误会直接导致任务执行失败；
- 输入文件夹内仅放置需要裂变的原图，不要混入无关文件；
- 大批量生成时，提前检查磁盘剩余空间，避免存储不足中断任务；
- 任务接口并发存在上限，最高 1 小时产出 4000-5000 张；
- 若需要透明背景素材，将【是否需要输出 png 格式图片】设置为 “是”；
- 裂变仅做同 IP 变体，不会替换主体 IP 元素。
