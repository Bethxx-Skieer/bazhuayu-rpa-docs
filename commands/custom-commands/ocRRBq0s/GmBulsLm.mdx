# 描述

获取服务-物流洞察-明细-退货物流总览-退货列表数据，保存到指定位置
![image](images/GmBulsLm-01.png)

# 配置说明
## 输入

<strong>网页对象:</strong>

任意一个已登录生意参谋的网页对象

<strong>违规类型:</strong>

选择违规类型

<strong>时间选择:</strong>

选择时间范围

<strong>保存文件夹：</strong>

选择文件保存路径

<strong>自定义文件名称：</strong>

自定义文件名称，若不填则使用默认文件名
## 输出

<strong>文件路径：</strong>

输出完整的文件路径，文本类型
