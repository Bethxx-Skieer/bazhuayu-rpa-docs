# 描述

获取服务-物流洞察-总览-核心指标数据，保存到指定位置
![image](images/GNuoZPOq-01.png)

# 配置说明
## 输入

<strong>网页对象:</strong>

任意一个已登录生意参谋的网页对象

<strong>时间选择:</strong>

选择时间范围

<strong>自定义日期:</strong>

格式必须为：YYYY-MM-DD

<strong>商品id:</strong>

输入商品id，选填，不填则默认全部商品

<strong>一级类目:</strong>

输入一级类目，必须与平台名称一致。选填，不填则默认全部一级

<strong>二级类目:</strong>

输入二级类目，必须与平台名称一致。选填，不填则默认全部二级

<strong>保存文件夹：</strong>

选择文件保存路径

<strong>自定义文件名称：</strong>

自定义文件名称，若不填则使用默认文件名
## 输出

<strong>文件路径：</strong>

输出完整的文件路径，文本类型
