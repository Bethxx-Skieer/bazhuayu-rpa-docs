# 描述

获取服务-物流洞察-诊断-物流异常-物流异常订单明细数据，保存到指定位置
![image](images/GWtcsNzd-01.png)

# 配置说明
## 输入

<strong>网页对象:</strong>

任意一个已登录生意参谋的网页对象

<strong>订单编号:</strong>

输入退款编号，选填，不填则默认全部

<strong>快递公司:</strong>

输入快递公司，必须与平台名称一致。选填，不填则默认全部

<strong>揽收城市:</strong>

输入揽收城市，必须与平台名称一致。选填，不填则默认全部

<strong>签收城市:</strong>

输入签收城市，必须与平台名称一致。选填，不填则默认全部

<strong>物流单号:</strong>

输入物流单号。选填，不填则默认全部

<strong>保存文件夹：</strong>

选择文件保存路径

<strong>自定义文件名称：</strong>

自定义文件名称，若不填则使用默认文件名
## 输出

<strong>文件路径：</strong>

输出完整的文件路径，文本类型
