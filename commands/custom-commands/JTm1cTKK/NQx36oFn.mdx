# 一、指令概述

该RPA指令依托新奇AI客户授权码（https://customer.xinqiai.cn/注册可获得试用，在个人中心获取SK开头），基于合规国内AI图像模型打造，是专门针对电商行业深度适配的文生图智能创作工具。无需上传任何参考图片，仅输入精准文字提示词，即可一键生成高清商用电商图片。指令支持自定义画面宽高比，覆盖1K-4K全档位分辨率自由输出，全面适配各大电商平台、短视频渠道、内容种草平台的图片尺寸与画质要求。

全程无需实拍原图、无需美工手动设计，依靠文字描述即可快速产出各类电商视觉素材，有效降低商品实拍成本、美工设计人力成本，全面提升店铺图片素材生产效率。单张图片处理成本0.28元，图片生成完毕后自动输出成品图片在线URL链接变量，可无缝衔接后续图片高清、去水印、商品上架等自动化流程。

<strong>重要限制</strong>：本指令仅支持单次单条提示词生成单张图片，不支持多条提示词批量一次性生成，大批量图片创作需搭配循环指令逐条执行。

# 二、参数配置说明



参数名称
示例/默认值
参数说明

授权码
新奇AI授权码（字符串）
填写已开通电商文生图权限的有效新奇AI授权码，用于调用国内AI文生图接口，支持静态固定填写与变量传入。

提示词
简约风保温杯商品主图，纯白背景，高清商业摄影，柔光光线，画面干净高级
自然语言描述图片主体、场景、风格、光影、构图等细节，描述越精准，生成图片越贴合需求；支持变量传入，可动态更换生成文案。

尺寸
2K（默认）
可选1K/2K/3K/4K四档分辨率，分辨率越高画面细节越丰富、画质越清晰，同时生成耗时和图片文件体积同步增加，按需选择即可。

宽高比
1:1（默认）
支持电商全场景常用比例：1:1商品主图、3:4竖版详情页、16:9海报banner，适配全平台图片尺寸规范。

生成的变量-成品图片URL
txt2img_result_url
输出变量，存储文生图生成后的高清图片在线链接，可直接被后续所有图片类RPA指令调用。

# 四、执行流程

指令运行后自动完成全流程无人值守处理：首先系统校验授权码有效性、提示词合规性、分辨率及宽高比参数合法性；随后将文字提示词上传至国内AI图像模型，AI按照设定尺寸和画面比例自动渲染生成高清电商图片；生成完成后自动返回图片在线链接，存入预设输出变量，全程无需人工干预。

# 五、运行效果

输入符合规范的文字提示词，即可一键生成构图标准、画质高清、光影自然的专业电商图片，画面无畸形元素、无模糊噪点，完全符合电商商用出图标准，直接获取在线图片链接，可直接用于店铺上架、活动装修、内容种草等全业务场景。

六、注意事项

前往https://customer.xinqiai.cn/注册账号可领取试用额度并获取SK开头授权码，新账号存在数据同步延迟，未显示授权码可等待几分钟后重新登录。正式使用需保证账户余额充足、文生图接口权限已开通，授权码过期、欠费、权限缺失均会导致接口调用失败。
指令仅支持单条文本提示词单次生成，不支持提示词数组、批量文本列表输入，批量生成必须搭配循环指令逐条运行。
提示词越详细具体，生成图片贴合度越高，建议补充产品外观、背景风格、画面光线、图片用途等关键信息；禁止输入违规、侵权、虚假宣传类提示词，违规内容会直接拦截无法出图。
分辨率按需合理选择，日常主图、详情页选用2K即可平衡画质与速度；4K高清大图适合首页海报、高端详情页，生成耗时会相对更长。
指令仅图片成功生成后扣费，提示词为空、网络断开、接口请求失败等未成功出图的情况，均不扣除账户费用。
指令运行全程必须保持网络通畅，离线环境无法调用AI生成接口，网络波动、防火墙拦截都会造成生成失败。
全部输入输出变量均为单值文本变量，不可使用列表、数组、数字等异常变量，避免出现参数读取失败、结果无法存储的问题。
