# 一、指令概述

该RPA指令需输入单张公开电商产品图片URL链接，配置本地存放文件夹路径以及目标保存图片格式，即可自动完成网络图片请求、原图下载、目录自动创建、图片格式转换、本地保存全套流程。全程保留原图画质，无画质压缩、无额外水印，可适配TEMU、亚马逊、Shein等跨境电商各类产品图片素材下载需求。下载完成后，图片完整本地存储路径自动存入自定义变量，可直接对接后续本地图片理解、图片修图、图片压缩等各类本地图片处理指令。

<strong>重要限制</strong>：本指令仅支持单条图片URL单独下载，不支持URL列表、批量链接一次性输入，批量图片下载需搭配RPA循环指令逐条执行。

# 三、使用示例
适用场景线上图片本地化存储：将电商店铺主图、详情图、营销海报线上链接一键下载至本地指定目录，完成素材备份；图片格式统一标准化：统一全网不同格式的产品图片，批量转为平台要求的JPG/PNG格式，满足上架规范；RPA流程上下游衔接：前置下载网络图片，为本地图片理解、本地图片翻译等仅支持本地路径的指令提供源文件；竞品素材自动采集：自动抓取竞品公开产品图片并分类保存，快速搭建本地竞品素材库。

# 四、执行流程

配置完成后运行指令，系统首先校验图片URL有效性、本地路径合法性以及图片格式合规性，随后发起网络请求拉取原图资源，自动检测并创建缺失的本地文件夹，再按照设定格式完成图片转码保存，最后校验本地文件完整性，将最终完整图片路径存入输出变量，全程全自动运行，无需人工干预。
# 五、运行效果

输入合规图片链接、本地目录及目标格式后，可在指定文件夹内生成无损原图，图片画质和源链接完全一致，自动适配指定保存格式；同时输出标准本地路径变量，可无缝衔接后续所有本地图片自动化处理流程。
六、注意事项图片链接必须为公开无防盗链链接，带登录验证、防盗链拦截、加密权限的图片链接无法正常下载，会触发系统内部异常报错，建议提前用浏览器无痕窗口验证链接可用性。本地文件夹路径仅支持绝对路径，禁止填写相对路径、网盘路径、移动设备临时路径，路径内不要包含特殊非法字符，避免目录创建失败。仅支持JPG、JPEG两种格式，填写其他小众格式会直接导致保存失败；格式转换为无损常规转换，不支持特殊透明通道保留等高阶图片处理需求。指令默认沿用原图自带文件名，若文件夹内存在同名同格式文件，会直接覆盖原有文件；如需保留历史文件，可搭配时间戳变量动态生成唯一文件名。单张下载图片大小建议不超过10MB，图片体积过大易受网络波动影响导致下载中断；网络超时、防火墙拦截均会造成下载失败，失败不会生成损坏文件，排查网络后可重新运行。所有输入、输出变量均为单值文本变量，不可使用列表、数组、数字等异常变量类型，否则会出现路径读取失败、结果无法存储的问题。
七、延伸应用批量图片自动下载：搭配RPA循环指令，遍历图片URL列表，逐条执行下载指令，实现大批量产品图片无人值守自动下载分类。全链路图片自动化：对接图片采集、图片理解、图片白底生成、图片翻译指令，实现线上图片采集→本地下载→AI智能处理一站式自动化流程。平台素材适配：根据不同跨境平台规则，动态切换保存格式，一键产出符合各站点规范的标准化产品图片素材。本地素材自动化管理：搭配文件重命名、文件夹分类指令，完成图片下载后自动规整文件，实现电商图片素材全流程自动化管理。
