# 描述

获取商品-商品360-内容分析数据，保存到指定位置
![image](images/bA6MZNhU-01.png)

# 配置说明
## 输入

<strong>网页对象:</strong>

任意一个已登录生意参谋的网页对象

<strong>商品id:</strong>

填写商品id
![image](images/bA6MZNhU-02.png)

<strong>分析类型：</strong>

选择分析类型

<strong>内容来源：</strong>

选择内容来源

<strong>文件保存路径：</strong>

选择文件保存路径

<strong>自定义文件名称：</strong>

自定义文件名称，若不填则使用默认文件名
## 输出

<strong>文件路径：</strong>

输出完整的文件路径，文本类型
