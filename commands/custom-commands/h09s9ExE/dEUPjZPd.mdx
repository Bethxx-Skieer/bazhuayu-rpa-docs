# 描述

获取商品-视频分析-整体概览数据，保存到指定位置
![image](images/dEUPjZPd-01.png)

# 配置说明
## 输入

<strong>网页对象:</strong>

任意一个已登录生意参谋的网页对象

<strong>素材来源:</strong>

选择素材来源

<strong>日期选择:</strong>

选择日期范围

<strong>自定义开始日期:</strong>

最少选择 1 天，最多选择 31 天，格式必须为：格式：YYYY-MM-DD

<strong>自定义结束日期:</strong>

最少选择 1 天，最多选择 31 天，格式必须为：格式：YYYY-MM-DD

<strong>保存文件夹：</strong>

选择文件保存路径

<strong>自定义文件名称：</strong>

自定义文件名称，若不填则使用默认文件名
## 输出

<strong>文件路径：</strong>

输出完整的文件路径，文本类型
