#
描述

用于识别纯数字、纯字母、数字+字母类验证码的文本并返回识别结果
![image](images/c5APdJQQ-01.png)

#
配置说明
##
输入

<strong>网页对象:</strong>

任意一个需要处理验证码的网页对象

<strong>验证码图片:</strong>

字符验证码的图片元素，如图
![image](images/c5APdJQQ-02.png)

##
输出

<strong>识别结果:</strong>

输出验证码识别的结果，文本类型
