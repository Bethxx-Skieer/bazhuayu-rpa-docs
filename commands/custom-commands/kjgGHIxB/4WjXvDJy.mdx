# 简体繁体转换
## 描述

将汉字转换成简体或者繁体
## 参数配置
![image](images/4WjXvDJy-01.png)

指令输入<strong>带转换文本:</strong> 转换的汉字<strong>转换方式:</strong> 有繁体、简体等各种选择项
指令输出<strong>转换结果</strong>:  转换后的结果
