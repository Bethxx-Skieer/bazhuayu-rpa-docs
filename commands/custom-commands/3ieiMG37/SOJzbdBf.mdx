## 1. 指令概述

该 RPA 指令用于在指定路径创建 SQLite 3数据库文件。如果目标路径下的数据库文件不存在，系统会自动创建一个新的 SQLite 数据库；若文件已存在，则不会重复创建，可直接进行后续数据库操作。

## 2. 配置参数
![image](images/SOJzbdBf-01.png)

参数名必填说明<strong>数据库文件路径</strong>是填写要创建的 SQLite 数据库文件的完整本地路径（如 D:/data/sales.db）。
## ## 3. 使用示例

假设需要在 D:/data/ 目录下创建名为sales.db 的数据库：在「数据库文件路径」输入框中填写 D:/data/sales.db；

4. 注意事项SQLite 数据库文件仅需单个文件即可存储完整数据，无需额外的服务端进程，适合轻量级数据存储场景。若需对已创建的数据库执行增删改查操作，可配合「执行 SQL 语句」等后续指令完成。常见错误：

<strong>路径无写入权限：</strong>当指定的文件路径所在目录没有写入权限时，指令执行失败。

<strong>路径无效：</strong>当填写的文件路径格式错误（如包含非法字符）或指向不存在的父目录。

<strong>文件被占用：</strong>如果目标路径的数据库文件已被其他程序锁定占用。
