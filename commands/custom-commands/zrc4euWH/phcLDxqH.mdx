# 输入

•网页对象： web_page

•开始时间：申请时间的开始时间与日期；格式必须是：<strong>YYYY-MM-DD HH:MM:SS</strong>；如：2025-03-03 12:20:00

•截止时间：申请时间的截止时间与日期；格式必须是：<strong>YYYY-MM-DD HH:MM:SS</strong>；如：2025-06-03 23:20:00

# 输出

•无输出
# 使用说明
## 1、使用该指令前需要打开到淘宝千牛页面，先进入【交易】【退款管理】打开【全部筛选项】

如：https://myseller.taobao.com/home.htm/trade-platform/refund-list

然后再使用指令，可以进行日期时间的选择。
