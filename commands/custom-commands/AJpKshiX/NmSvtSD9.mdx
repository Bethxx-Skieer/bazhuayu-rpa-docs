# # 获取图层文字
## 描述

该指令获取 PS 文字图层的文字
## 参数配置
### 指令输入

Photoshop 文件路径

图层名: 字符串 ; 图层的名称, 找不到该图层会报错

![image](images/NmSvtSD9-01.png)

### 指令输出

输出为字典类型  text_content

\{

"success": true,

"file_path": "D:\\444.psd",

"file_name": "444.psd",

"layer_name": "123",

"text_content": "成功了",

"layer_type": "2"

\}
![image](images/NmSvtSD9-02.png)
