# # 导出为图片
### 描述

将 Photoshop 文件的内容保存为图片。
### 配置项说明
#### 输入

psd文件路径

导出质量： 导出图片的质量, 目前仅支持 jpg 格式的图片, 范围 1-12

保存路径： 要保存的图片路径，保存路径需以 png、jpg结尾
