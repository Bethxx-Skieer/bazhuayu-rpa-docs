# # 获取所有图层名
### 描述

获取 Photoshop 文件的所有图层名字。
### 配置项说明
#### 输入

Photoshop 文件路径
![image](images/E0LXe2mU-01.png)

#### 输出

所有图层名： 所有图层的名字，输出为字典类型

\{

"success": true,

"file_path": "D:\\444.psd",

"file_name": "444.psd",

"total_layers": 14,

"layer_names": [

"图层 3",

"111",

"图层 2",

"图层 1",

"name1"

]

\}
![image](images/E0LXe2mU-02.png)
