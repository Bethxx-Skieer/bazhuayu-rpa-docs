# # 替换图层图片
### 描述

在打开的 Photoshop 文件中按图层名找到图层，将这个图层的内容替换为指定的图片。
### 配置项说明
#### 输入

psd文件路径：

图层名： 图层名。不是图层的文字内容。

图片路径： 要替换为的图片文件路径，支持常见的图片格式。
