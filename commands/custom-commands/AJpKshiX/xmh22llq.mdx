# # 显示/隐藏图层
### 描述

按图层名找到一个图层，显示或隐藏这个图层。
### 配置项说明
#### 输入

psd文件路径：

图层名： 图层名，可在ps里面查看图层名称

设置为： 设置为隐藏或者显示。
![image](images/xmh22llq-01.png)

### 输出示例

\{

"success": true,

"layer_name": "111",

"previous_visible": true,

"current_visible": false,

"action": "隐藏",

"file_saved": true,

"file_path": "D:\\333.psd",

"file_name": "333.psd"

\}
