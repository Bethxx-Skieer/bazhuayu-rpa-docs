# 输入

•网页对象： web_page

•快捷日期选择：可以下拉框快捷选择“今天”、“昨天”、“过去7天”、“过去15天”、“过去30天”选项；若选择“自定义日期”，需要填写自定义日期参数yyyy-mm-dd。

•自定义日期：“自定义日期”日期格式必须为：yyyy-mm-dd~yyyy-mm-dd，如2025-05-06~2025-05-29；注意网页页面仅支持查询31天之间的数据。

•文件下载路径： 下载导出的文件保存的文件夹位置。
# 输出

•无输出
