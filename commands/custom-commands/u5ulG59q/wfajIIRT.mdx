# 描述

获取账户-账户明细-现金收支明细数据，保存到指定位置
![image](images/wfajIIRT-01.png)

# 配置说明
## 输入

<strong>网页对象:</strong>

任意一个已登录万象台无界版的网页对象

<strong>专款类型:</strong>

选择专款类型
![image](images/wfajIIRT-02.png)

<strong>交易类型:</strong>

选择交易类型

<strong>时间类型:</strong>

选择时间类型

<strong>日期选择:</strong>

选择日期范围

<strong>自定义开始日期:</strong>

最少选择 1 天，格式必须为：格式：YYYY-MM-DD

<strong>自定义结束日期:</strong>

最少选择 1 天，格式必须为：格式：YYYY-MM-DD

<strong>查询专款id:</strong>

填写专款id，选填，若不填则默认全部数据

<strong>保存文件夹：</strong>

选择文件保存路径

<strong>自定义文件名称：</strong>

自定义文件名称，若不填则使用默认文件名
## 输出

<strong>文件路径：</strong>

输出完整的文件路径，文本类型
