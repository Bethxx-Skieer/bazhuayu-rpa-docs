# 输入

•网页对象： web_page

•快捷日期选择：可以下拉框快捷选择“今日实时”、 “昨日”、 “近7天”、“近15天”、“近30天”选项；若选择“自定义日期范围”，需要填写自定义日期参数yyyy-mm-dd~yyyy-mm-dd。

•自定义日期范围：“自定义日期范围”日期格式必须为：yyyy-mm-dd~yyyy-mm-dd，如2025-05-06~2025-06-06；注意网页页面仅支持查询近31天的数据。

# 输出

•无输出
# 使用说明
## 1、使用该指令前需要打开到淘宝联盟-商家中心页面，点击进入到【数据分析】页面，先进入【推广概况】或者【商品分析】页面（如图）；

此质量可以适配【推广概况】、【商品分析】的时间日期快捷选择/自定义日期范围选择。

如：https://ad.alimama.com/portal/v2/report/promotionDataPage.htm
