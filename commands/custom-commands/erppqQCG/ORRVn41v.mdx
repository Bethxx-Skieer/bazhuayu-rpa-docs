# 输入

•网页对象 web_page

•快捷日期选择：下拉框选择快捷日期。若选择“自定义日期范围”，则需填写”自定义日期范围“的参数值。

•自定义日期范围：自定义日期格式：yyyy-mm-dd~yyyy-mm-dd，例：2025-05-12~2025-06-04。快捷日期选择“自定义日期范围”，才会生效此参数。
# 输出

•无输出
