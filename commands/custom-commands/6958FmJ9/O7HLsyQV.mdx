# 一.功能描述

该指令用于切换亚马逊广告平台的语言。
![image](images/O7HLsyQV-01.png)

# 二.使用参数说明
## 1.输入参数

<strong>网页对象：</strong>

传入已打开的网页对象。

<strong>选择语言：</strong>

请输入需要切换的语言，要和网页上显示的一致。

例如：English (US)、中文（简体)
