# 描述

该指令实现服务-评价分析页面的时间选择功能
![image](images/mNblmjhV-01.png)

# 配置说明
## 输入

<strong>网页对象:</strong>

任意一个已登录京东商智商家版后台服务-评价分析的网页对象

<strong>时间查询方式：</strong>

下拉框，可选按天查询、按周查询、按月查询、近7天、近30天。选填，若不填则使用平台默认值
