# 一.功能描述

在本指令中输入账号密码可以实现登录京东商智品牌版操作
# 二.使用参数说明
## 1.输入参数

网页对象：京东商智（品牌版）登陆页面的网页对象
![image](images/1guWbbHU-01.png)

账号：需要登录的账号

密码：需要登录账号的密码

偏移量：当滑块按钮移动距离不能完成拼图时，可以通过偏移量进行微调，如每次滑动距离都差3px，则输入3，滑动距离超过4px，则输入-4
## 2.输出参数

已登录网页: 输出登录完成的网页对象
