# <strong>一、指令概述</strong>

该 RPA 指令用于<strong>将本地文件上传至飞书云盘指定文件夹</strong>，执行后返回上传文件的唯一标识（file_token），适用于本地文件的飞书云盘备份、自动化上云等场景。

飞书官方开发文档参考：https://open.feishu.cn/document/server-docs/docs/drive-v1/upload/upload_all

## <strong>三、使用示例（本地文件上传至飞书云盘场景）</strong>
### <strong>场景：将本地文件 “报表.xlsx” 上传至飞书云盘目标文件夹（Token：fldbc****************）。</strong>
#### <strong>参数配置：</strong>

• 指令：上传文件

• 飞书访问凭证：feishuAuthToken（通过 “获取飞书访问凭证” 指令生成的变量）

• 文件夹 Token：fldbc****************（目标文件夹唯一标识，关键字符已打码）

• 文件路径：C:\Reports\报表.xlsx（本地待上传文件路径）

• 运行结果：uploadResult（自定义变量，存储上传结果）
#### <strong>执行流程：</strong>

调用该 RPA 指令后，RPA 会通过 feishuAuthToken 完成飞书 API 认证，根据打码后的文件夹 Token 和本地文件路径，将文件上传至飞书云盘指定文件夹；上传完成后，将包含file_token的结果存入 uploadResult 变量，便于后续文件管理（如移动、分享）等操作引用该文件标识。
## <strong>四、返回结果说明</strong>
### <strong>飞书 API 标准返回示例（成功场景）：</strong>

指令执行后，“运行结果” 变量（如uploadResult）会存储包含上传文件标识的 JSON 结果，格式如下：

\{ "code": 0, "msg": "success", "data": \{ "file_token": "boxcnrHpsg1QDqXAAAyachabcef" \}\}
### <strong>响应字段含义：</strong>

• code：状态码，0 表示文件上传成功，非 0 为失败（具体错误码含义参考飞书官方文档）。

• msg：提示信息，success 表示上传成功。

• data.file_token：上传后文件的唯一标识 Token，是飞书云盘操作该文件的核心身份标识（如后续移动、删除文件需引用此 Token）。
## <strong>五、注意事项</strong>

1. <strong>访问凭证权限</strong>：“飞书访问凭证” 需具备<strong>文件上传权限</strong>（如 “Upload file” 权限）且未过期，否则会返回 code=403（权限不足）错误。

2. <strong>文件夹 Token 有效性</strong>：文件夹Token 需为飞书云盘<strong>合法存在的文件夹 Token</strong>（打码不影响实际值校验），否则会返回 code=404（目标文件夹不存在）错误。

3. <strong>文件路径合法性</strong>：本地 “文件路径” 需指向<strong>真实存在的文件</strong>（避免选择快捷方式或不存在的路径），否则会返回文件读取失败错误。

4. <strong>上传限制</strong>：飞书 API 对上传文件的大小、格式有一定限制（具体参考飞书官方文档），超出限制会导致上传失败，需提前确认文件符合要求。
## <strong>六、延伸应用</strong>

可结合 RPA 的 “新建文件夹”“移动文件” 指令，实现<strong>本地文件自动化云盘管理</strong>：例如本地生成日报表后，自动调用 “上传文件” 指令将其上传至飞书临时文件夹，再调用 “移动文件” 指令将其移动到 “日报表归档” 文件夹，替代人工手动上传和整理的重复工作，提升文件上云效率。
