# 描述

获取市场-竞争监控-监控看板-竞品列表数据，保存到指定位置
![image](images/WysPeVtU-01.png)

# 配置说明
## 输入

<strong>网页对象:</strong>

任意一个已登录生意参谋的网页对象

<strong>店铺类型:</strong>

选择店铺类型

<strong>日期选择:</strong>

选择日期范围

<strong>自定义日/周/月:</strong>

自定义日/周/月，若为日/周，格式必须为：YYYY-MM-DD，若为月，格式必须为：YYYY-MM

<strong>文件保存路径：</strong>

选择文件保存路径

<strong>自定义文件名称：</strong>

自定义文件名称，若不填则使用默认文件名
## 输出

<strong>文件路径：</strong>

输出完整的文件路径，文本类型
