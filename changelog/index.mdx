八爪鱼RPA 持续迭代更新，不断优化产品体验、扩充自动化能力。以下按版本倒序记录每次发布的主要内容。

<Info>
最新版本：**v2.8.12**。变更内容按 **新增 / 优化 / 修复** 三类归纳；如需了解某条变更的具体用法，可前往对应指令文档或 [八爪鱼RPA 社区问答](https://rpa.bazhuayu.com/community/questions)。
</Info>

> **图例**：**新增** = 新功能 / 新指令 · **优化** = 体验与性能改进 · **修复** = 问题修复

## v2.7.12

### 新增

- 八爪鱼 RPA MCP：在GPT、Dify、Claude Code 等支持 MCP 的客户端中，让 AI 直接调用八爪鱼 RPA 流程，打通"自然语言指令→实际系统操作"的最后一公里。
- API Key授权：开放 API 新增 API Key 鉴权方式，集成更简单、调用更安全，并支持按 Key 管理权限与用量。
- 启动时设置代理：客户端启动时即可配置网络代理，满足内网访问、IP轮换与多账号隔离等场景，启动后直接生效。

### 修复

- 修复部分BUG、优化部分功能交互和提升产品UI体验


## v2.6.67

### 新增

- 桌面自动化能力增强-新增对 SAP、用友等企业级客户端的操作支持，覆盖更多核心业务系统。
- 触发器页面升级-新增快捷筛选入口，一键定位上次运行状态与最近失败任务，排查问题更直接。
- 机器人页面升级-新增使用引导与可用机器人快捷筛选，降低新用户上手门槛。
- 飞书多维表格批量写入-支持批量添加记录指令，解决逐行写入速度慢的问题，大数据量场景性能显著提升。
- 时间戳转换扩展-日期转换指令新增对飞书、Excel 表格时间戳格式的支持。

### 优化

- 运行效率提升-运行应用时可直接调用历史参数，无需重复填写，重复任务启动更快。
- 元素编辑器增强-可设置属性"存在"或"不存在"条件，元素识别逻辑更灵活。
- 企业管理优化-套餐到期续费后，可在管理后台直接恢复成员账号，减少运营中断。
- 开发者能力增强-开发者后台新增已上架应用报错信息查看，线上问题定位更高效。

### 修复

- 修复部分BUG、优化部分功能交互和提升产品UI体验
