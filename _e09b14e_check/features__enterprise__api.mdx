## 功能概述

八爪鱼RPA 企业版提供开放 API 接口，支持企业将 RPA 能力集成到自身业务系统、内部平台或第三方应用中。通过令牌（Token）鉴权，可以远程启动应用、查询运行状态、管理机器人资源，无需人工登录客户端即可完成自动化调度。

所有接口统一以 `https://api-rpa.bazhuayu.com/api/v1` 为基址，请求头需携带 `Authorization: Bearer <token>`；企业版还可选携带 `EnterpriseId` 请求头以指定企业上下文（缺省为个人版）。

## 使用流程

1. 调用「授权」接口，使用账号密码换取访问令牌（Token）。
2. 在请求头中携带 `Authorization: Bearer <token>`。
3. 按需调用「启动应用」「机器人调度」等接口，远程执行自动化任务。
4. 通过「查询应用状态」「机器人列表」等接口获取执行结果与资源信息。
