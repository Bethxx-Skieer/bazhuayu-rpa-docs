## 功能概述

底部菜单栏位于流程编辑器下方，主要用于调试与排查问题。它实时展示流程运行中的错误、日志、变量值与引用关系，帮助开发者快速定位异常并优化流程。

## 入口

进入任意应用的流程编辑界面，底部区域即为底部菜单栏。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 错误列表 | 展示流程编排中不合规指令的错误信息、流程名称与行号 |
| 运行日志 | 实时输出每条指令的运行结果与【打印日志】内容 |
| 变量值 | 查看流程内所有变量的当前值，便于检查输出异常 |
| 查找引用 | 查看变量、元素和指令在流程中的各处引用情况 |

![底部菜单栏 - 错误列表与运行日志](images/Gc48az-24.png)

## 使用流程

1. 在流程编辑区搭建或修改指令。
2. 如有配置错误，在「错误列表」中查看具体错误与位置。
3. 点击「运行应用」，切换到底部「运行日志」查看执行输出。
4. 通过「变量值」面板检查关键变量是否符合预期。
5. 使用「查找引用」追踪变量/元素在流程中的使用位置，便于批量修改。

<Info>
  编辑界面的调试运行日志在关闭编辑界面后会自动清除；如需长期保留运行记录，请前往「运行计划」→「运行日志」查看本地运行日志。
</Info>
