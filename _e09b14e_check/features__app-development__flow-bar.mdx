## 功能概述

流程栏位于流程编辑器的中间区域，是流程编排的核心画布。用户通过拖拽指令、调整顺序、设置分支与循环，将业务逻辑转化为可执行的 RPA 流程。

## 入口

进入任意应用的流程编辑界面，中间空白区域即为流程栏。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 添加指令 | 在流程栏空白处点击，或从左侧指令栏拖拽指令到此处 |
| 编辑指令 | 选中指令后右键，可重命名、复制、禁用或删除 |
| 调整顺序 | 拖拽指令上下移动，改变执行顺序 |
| 设置断点 | 在调试运行前设置断点，便于逐条排查 |
| 排列流程 | 多条指令按业务逻辑排列，构成完整自动化流程 |

## 一条指令的配置

在流程编辑区点击即可新增指令；或选中已有指令，从左侧指令区将其拖拽至流程编辑区。

![流程栏 - 单条指令配置](images/Gc48az-22.png)

## 一个流程的搭建

多条指令按一定逻辑排列，即可构成一个自动化流程。

![流程栏 - 流程搭建](images/Gc48az-23.png)

## 使用流程

1. 从左侧指令栏选择指令，拖入流程栏。
2. 按业务顺序排列指令，形成主流程或子流程。
3. 选中指令，在右侧参数栏配置输入、输出与判断条件。
4. 点击「运行应用」调试流程，观察运行结果。
